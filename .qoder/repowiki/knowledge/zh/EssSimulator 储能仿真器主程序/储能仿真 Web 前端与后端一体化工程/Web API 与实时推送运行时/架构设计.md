本模块是仿真系统的 Web 运行时层，围绕 ASP.NET Core 管道组织：
- 端点注册：`EndpointExtensions.MapSimulatorEndpoints` 集中挂载 `/api/*` REST 接口（健康检查、主接线、电池/簇快照、BMS 门限、告警、连接、配置、协议端口、断路器控制、通用命令、dpctest 异步测试、白盒切片、组态编辑等），并通过扩展方法挂载拓扑与系统配置子路由。
- 实时通道：`RealtimeHub` 继承 `Microsoft.AspNetCore.SignalR.Hub`，定义频道常量 `RealtimeChannels` 与方法名常量 `RealtimeMethods`；通过 `IHubContext<RealtimeHub>` 按频道分组推送，支持前端 `JoinChannel/LeaveChannel` 订阅。
- 周期采样：`SnapshotService` 继承 `BackgroundService`，等待仿真就绪后以 `WebConfig.SnapshotIntervalMs`（50~5000ms）循环读取主接线、连接、各舱 BMS 快照及全局告警，经 SignalR 推送到对应频道；通过 `RequestImmediatePush` + `TaskCompletionSource` 实现外部触发即时推送。
- 日志桥接：`LogHubAppender` 继承 log4net `AppenderSkeleton`，将日志事件转为 `LogEntryDto` 入队到 `LogHubBridge.ConcurrentQueue`（最大 2000 条背压丢弃），由 `LogHubDispatcher` BackgroundService 消费并推送到 `logs` 频道。
- 命令执行：`WebCommandExecutor` 封装 `CommandProcessor`，注册 `EssCommand/BreakerCommand/DataPointChangeCommand/DpcAutoTestCommand`，同步执行 `esscmd/breaker/dpc` 命令，并异步执行 dpctest 用例，通过 cmdprogress 频道推送进度。
- 数据装配：`MainLineEnricher` 从 `GuiSimDataAccess`/`TopologyStore` 组装 `MainLineViewModel`（含 PCS/BMS/PV 单元、工程模式拓扑注入），作为 `/api/mainline` 响应与 SnapshotService 推送源。
- 鉴权：`ApiKeyAuthMiddleware` 在管道中拦截 `/api/*`（豁免 `/api/health`），从 `X-Api-Key` 或 `Authorization: Bearer|ApiKey` 头提取密钥，使用 `CryptographicOperations.FixedTimeEquals` 防时序攻击比对。
依赖方向：Web 层 → 核心仿真 (`EssSimulator.Core`, `Display`, `Configuration`)，不反向被核心引用；SignalR 仅通过 `IHubContext` 解耦。
