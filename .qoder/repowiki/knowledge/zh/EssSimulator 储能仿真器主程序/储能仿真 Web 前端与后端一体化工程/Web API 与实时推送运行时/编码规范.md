- SignalR 推送统一通过 `IHubContext<RealtimeHub>` 调用 `Clients.Group(RealtimeChannels.X).SendAsync(RealtimeMethods.ReceiveX, payload)`，频道与方法名均以静态常量集中声明，避免硬编码字符串。
- 后台服务（`SnapshotService`、`LogHubDispatcher`）继承 `BackgroundService`，在 `ExecuteAsync` 中使用 `CancellationToken` 驱动循环，并在 finally/catch 中忽略推送失败以保证主流程健壮性。
- REST 端点采用 Minimal API 风格 `MapGet/MapPost` 内联委托，参数通过 DI 解析（如 `TopologyStore`、`IOptions<T>`、`WebCommandExecutor`），返回 `Results.Ok/BadRequest/NotFound` 等强类型结果。
- 对外暴露的 DTO（`LogEntryDto`、`MainLineViewModel` 及其嵌套视图模型）使用 sealed class + 可空默认值，字段命名与前端展示语义对齐（如 `UnitNumber` 1-based）。
- 对可能失败的底层访问（SnapshotService 单舱推送、LogHubAppender.Append、MainLineEnricher.AttachTopology）统一 try-catch 吞异常，确保单个设备/组态加载失败不影响整体服务。
- 命令执行结果通过统一的 `CommandResult` 包装，REST 层用 `FromCommandResult` 转换为 `Ok`/`BadRequest` 响应，保持错误处理一致性。
