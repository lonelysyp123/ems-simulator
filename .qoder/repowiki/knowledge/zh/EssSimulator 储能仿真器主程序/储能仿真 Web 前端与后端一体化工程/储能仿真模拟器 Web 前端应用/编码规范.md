- 路由与菜单项一一对应，新增页面需在 `router.js` 注册并同步在 `App.vue` 侧栏添加对应 `el-menu-item`。
- 视图级功能开关统一通过 `editionFeatures`（allowMainline3d / allowTopologyEditor / allowDroopSlices）在模板中以 `v-if` 控制可见性。
- 跨视图共享状态集中在 `services/` 下的模块（api、constants、systemLock、editionFeatures），视图组件不自行维护全局数据。
- SignalR 实时事件通过 `services/constants.js` 中定义的 `RealtimeMethods.*` 常量订阅，避免硬编码字符串。
- 路由采用 `createWebHistory` 模式并以 `meta.title` 标注页面标题，便于后续扩展面包屑或标签页。
