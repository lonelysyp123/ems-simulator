应用以 `main.js` 为入口，启动时先加载 `editionFeatures` 决定功能开关，再挂载 Element Plus（含中文本地化）和 `router.js`。`App.vue` 提供侧栏菜单+主内容区的壳布局，并通过 `systemLock` 状态在系统重新初始化期间全屏锁定；所有页面均通过 `<router-view />` 渲染。`router.js` 集中声明 `/mainline`、`/mainline-3d`、`/topology`、`/battery`、`/cells`、`/thresholds`、`/alarms`、`/command`、`/droop-slices`、`/connections` 等路由，并在 `beforeEach` 中结合 `systemLock` 与 `editionFeatures` 做导航守卫。各子模块（mainline_visualization、topology_editor、battery_cells_monitoring、system_management）作为独立 `views/*.vue` 组件按路由懒加载，共享 `services/api.js`（HTTP/SignalR 客户端）、`services/constants.js`（RealtimeMethods）、`services/systemLock.js`（全局锁）与 `services/editionFeatures.js`（版本能力），从而在不直接耦合的情况下实现跨视图的状态同步与权限控制。
