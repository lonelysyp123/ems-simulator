- 节点几何与端口坐标统一通过 `nodeLayout.js` 的 `nodeSize`、`portPosition`、`formatVoltage`、`templateColor` 等函数计算，避免在各组件中硬编码尺寸与颜色。
- 画布交互采用“父组件持有状态 + 子组件 emit 事件”的模式：TopologyCanvas 只负责鼠标/滚轮事件与 SVG 更新，选中态、连线态、移动结果全部交由 TopologyView 管理。
- 撤销/重做通过 JSON 快照数组（historyPast/historyFuture，上限 HISTORY_MAX=40）实现，每次修改先 pushHistory 再 applyProject，应用历史时设置 applyingHistory 标志防止递归触发。
- 主接线布局算法以无向邻接表（Map<NodeId, Set<NodeId>>）表示拓扑，通过 BFS/DFS 遍历识别母线、变压器、挂接负载与馈线，再分帧测量与放置。
- 设备卡片（PCS/BMS/PV箱变/PV方阵）统一通过 Vue 的 `defineComponent` + `h()` 函数式渲染，并以 `foreignObject` 嵌入 HTML 表单控件，配合 `getDraft/setDraft` 本地草稿暂存用户输入。
- 对布尔型参数的读取统一用 `truthy(v)` 或显式判断 `true/'true'/1`，兼容后端可能返回字符串形式的布尔值。
