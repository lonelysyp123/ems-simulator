模块由三层构成：
- 顶层视图 `TopologyView.vue` 作为页面容器，维护项目数据（nodes/edges）、模板库、设备库、撤销/重做历史栈、校验结果等状态，通过 Element Plus 表单/对话框组织工具栏、调色板、属性面板和向导弹窗；所有持久化操作经 `@/services/api.js` 调用后端。
- 画布层 `components/topology/TopologyCanvas.vue` 是纯 SVG 渲染组件，负责缩放/平移、节点拖拽、端口点击连线、网格吸附与边路径计算，并通过 `emit` 向上抛出 select-node/select-edge/port-click/move-node/pointer-world 事件，仅暴露 `clientToWorld` 给父组件。
- 布局工具层 `nodeLayout.js` 集中定义 GRID_SIZE、各 templateId 的尺寸、端口位置计算、电压格式化与模板配色，被 TopologyCanvas 与 TopologyView 共同复用。
- 独立的主接线视图 `TopologyMainLineSvg.vue` 接收运行时快照 `snap`，通过 `topologyMainLineLayout.js` 将拓扑图的 nodes/edges 构建为无向图并递归推导站侧骨架（电网→母线→变压器→电表→负载），再按 EMU/光伏单元展开 PCS/BMS/直流母线等内部结构，输出 wires/buses/transformers/meters/loads/stemBreakers/units 等布局数据供 SVG 渲染。
依赖方向单向：ToplogyView → TopologyCanvas → nodeLayout；TopologyMainLineSvg → topologyMainLineLayout，两者互不引用。
