- HTTP 请求统一通过 `api.js` 中基于 axios.create(baseURL: '/api') 创建的实例发起，响应拦截器将后端返回的 message 包装为 Error 抛出。
- 长连接与异步初始化采用「Promise 缓存」模式：`getHub()` 与 `loadEditionFeatures()` 均只创建一次 Promise 并复用，避免重复连接或重复请求。
- 服务端能力开关通过 `editionFeatures.js` 暴露的 `getEditionFeatures()` 读取，并在 `App.vue` 菜单与 `router.js` 路由守卫两处同时消费，保证 UI 与路由权限一致。
- SignalR 相关常量（方法名、频道名）集中在 `constants.js` 中以对象形式导出，组件通过 `useRealtime` Hook 订阅时引用这些常量而非硬编码字符串。
- 全局可变状态使用 Vue `reactive` 暴露写操作函数（如 `lockSystem/updateSystemProgress/unlockSystem`），并以 `readonly(state)` 形式导出供组件只读订阅。
- 路由组件一律采用动态 `import()` 懒加载，并在 `meta.title` 中声明页面标题，便于后续扩展面包屑或文档生成。
