模块以 `main.js` 为唯一入口，创建 Vue 应用并挂载 ElementPlus（中文 locale）与 vue-router，启动前调用 `loadEditionFeatures()` 预取后端档位配置；`App.vue` 作为根组件提供固定头部 + 左侧 `el-menu` 导航 + `<router-view>` 主体，并通过 `systemLock` 状态渲染全屏遮罩阻止交互；`router.js` 集中声明所有视图路由（懒加载），在 `beforeEach` 中依据 `isSystemLocked()` 与 `isEditionRouteAllowed()` 拦截跳转，实现基于档位的页面级权限控制。

`services/` 是独立于 UI 的全局服务层：`api.js` 用 axios 封装 `/api/*` REST 接口并提供单例 SignalR Hub（`getHub()` 缓存连接），暴露健康检查、告警、组态编辑、拓扑工程、系统配置等全部后端方法；`editionFeatures.js` 维护一份进程内 features 缓存，通过 `getConfig().edition` 解析出 `allowDroopSlices / allowMainline3d / allowTopologyEditor` 三枚开关，并在路由守卫与菜单项中消费；`systemLock.js` 使用 Vue `reactive` + `readonly` 暴露可被任意组件订阅的「系统重新初始化」锁状态，配合 CSS 中的 `.system-lock-mask` 实现全局阻塞；`constants.js` 集中定义 SignalR 方法名与频道名，`useRealtime.js` 提供组合式 Hook 自动 JoinChannel/LeaveChannel 并管理回调生命周期。

依赖方向单向：`App.vue` → `services/*` → 后端；`router.js` 仅依赖 `services/systemLock` 与 `services/editionFeatures`；样式集中在 `styles/app.css`，通过 `main.js` 全局引入。
