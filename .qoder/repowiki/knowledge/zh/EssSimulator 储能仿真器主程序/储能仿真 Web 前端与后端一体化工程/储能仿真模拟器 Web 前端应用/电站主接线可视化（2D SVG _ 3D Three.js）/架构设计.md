模块以 Vue 单文件组件为入口：`MainLineView.vue` 渲染 2D 主接线（含概览指标、表格），通过 `v-if` 在工程模式下切换至 `TopologyMainLineSvg`；`MainLine3dView.vue` 渲染 3D 场景，两者均通过 `useRealtime(RealtimeChannels.MainLine)` 订阅后端推送的 `snap` 快照，并以事件冒泡方式将断路器切换、PCS/BMS/PV 控制命令经 `@/services/api.js` 的 `postCommand` 下发。

- 2D 视图层：`MainLineSvg.vue` 用原生 SVG + `foreignObject` 绘制 220kV→主变→35kV 母线→690V 母线的层级拓扑，每个储能单元按 A/B 两侧展开 PCS+BMS 支路，内部 `ChannelBranch` 子组件负责支路内按钮与输入框。
- 3D 视图层：`MainLineScene.vue` 仅作为容器与工具栏，实例化 `mainline3d/SceneController.js` 管理 Three.js 生命周期（WebGLRenderer、CSS2DRenderer、相机、灯光、阴影、全屏）。`SceneController` 通过 `project3dLayout.js` 计算站点布局，调用 `buildMeshes.js` 构建站级网格，`powerFlow.js` 驱动电缆颜色动画，`interaction.js` 处理点击/双击/悬停拾取，`deviceDetail.js` 生成 PCS/BMS 剖切详情模型与悬浮面板，`pvArrayLayout.js` 负责光伏方阵排布。
- 数据流单向：后端 → `useRealtime` → `snap` ref → 各组件 computed/table/svg/three 更新；用户操作 → emit 事件 → View 层 `runChannelCommand` 构造 `esscmd`/`dpc` 指令串 → API 调用。
- 依赖方向：View → Component → `mainline3d/*` 纯 JS 模块；`mainline3d` 内部仅依赖 Three.js 与自身子模块，不反向依赖 Vue。
