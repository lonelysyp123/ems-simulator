- 所有用户控制动作（断路器、PCS 启停/功率、BMS 上电/SOC、PV 启停/温度/角度）统一封装为 `onXxx` 处理器，先做数值校验再调用 `runChannelCommand` 拼接 `esscmd`/`dpc` 指令字符串并通过 `postCommand` 发送。
- 实时数据通过 `useRealtime(RealtimeChannels.MainLine, { [RealtimeMethods.ReceiveMainLine]: data => snap.value = data })` 订阅，View 层仅维护一个 `snap` ref，UI 由 computed 派生表格行与样式。
- PCS 有功/无功目标值通过 `resolvePcsModbus(pcsNumber, kind)` 映射到 `simEmu{ceil(N/2)}.ytX` 点号，奇偶路分别对应 yt0/yt1 或 yt4/yt5，并在 2D 与 3D 两套视图中复用同一映射逻辑。
- 3D 场景采用 SceneController 类封装 Three.js 生命周期，通过 `updateFromSnap(snap)` 增量更新网格与标签，并在 `watch({ deep: true })` 中响应快照变化，销毁时在 `onBeforeUnmount` 中清理监听器、退出全屏并调用 `dispose()`。
- 2D 支路组件 `ChannelBranch` 与 3D 设备详情 `deviceDetail.js` 均以工厂函数形式创建 Mesh/Group，并通过统一的 `MAT.*` 材质工厂与 `box/cyl` 辅助函数构建几何体，便于复用与释放。
- 电压/频率/功率等物理量统一通过 `fmtVolt`、`fmtHz`、`fmtKw`、`fmtKvar` 等格式化函数输出，空值一律返回 `—`，保持 UI 文案一致。
