- 所有视图在 `onMounted` 中先调用 `getConfig()` 读取 `simulator.channelCount`/`unitCount` 以动态填充单元下拉选项，失败时静默忽略并回退默认值。
- 对后端 API 调用统一采用 try/catch 包裹并将错误输出到 `console.warn` 或 `ElMessage.error`，保证页面不因单个请求失败而崩溃。
- 阈值/工程值与原始寄存器值之间的换算通过本地函数完成：`rawOf` 计算 `engineeringValue × scale` 取整，`precisionOf` 根据 scale/unitHint 决定输入框精度。
- 实时数据更新采用增量 patch 策略（如 AlarmsView 的 `patchSnap` 按 deviceId/flagName 合并新旧快照），避免整表替换导致 DOM 闪烁。
- 组件内状态使用 `ref`/`reactive`/`computed` 组合：筛选条件用 ref，派生列表用 computed（如 `filteredRows`、`visibleDevices`、`dirtyRows`），保持模板只读。
- 资源清理遵循成对模式：ECharts 实例在 `onBeforeUnmount` 中 `dispose()`，SignalR hub 在卸载时 `off` 事件监听并 `leaveGroup`，定时器在 `clearInterval` 中释放。
