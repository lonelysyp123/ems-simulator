本模块由四个并列的 Vue 3 `<script setup>` 单文件组件组成，分别对应 `BatteryView.vue`（舱级总览 + ECharts 簇 SOC/功率柱折线图）、`CellsView.vue`（按包/单体二维网格显示电压并高亮最高/最低值）、`ThresholdsView.vue`（BMS 告警门限表格编辑并通过 dpc 命令下发）、`AlarmsView.vue`（BMS/PCS 设备告警标志位列表）。所有组件均通过共享的 `@/services/api.js` 调用后端 REST 接口（如 `getBattery`、`getCells`、`getConfig`、`getRackThresholds`、`postCommand`、`getAlarms`），并在需要时通过 `@/services/constants.js` 中的 `RealtimeMethods`/`RealtimeChannels` 配合 `getHub()` 订阅 SignalR 通道实现实时推送（仅 BatteryView 使用）。组件之间无相互引用，依赖方向单向指向 services 层；每个页面独立管理自身状态（ref/reactive/computed），通过 Element Plus 的 el-table、el-select、el-tag 等组件构建 UI，图表渲染由 ECharts 在 `onMounted`/watch 中按需初始化与销毁。
