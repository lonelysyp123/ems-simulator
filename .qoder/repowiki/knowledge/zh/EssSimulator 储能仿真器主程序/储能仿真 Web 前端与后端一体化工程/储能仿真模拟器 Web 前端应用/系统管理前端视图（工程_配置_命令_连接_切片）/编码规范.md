- 每个视图组件均为独立的 `.vue` 单文件，使用 `<template>` + `<script setup>` + `<style scoped>` 三段式结构，职责单一且无子组件拆分。
- 数据加载统一采用 `onMounted` 中调用异步 `reload`/`refresh` 函数，并在 try/catch 中使用 `ElMessage.error` 上报错误，finally 中重置 loading 状态。
- 危险操作（删除工程、清空切片、确认重启）一律先弹出 `ElMessageBox.confirm` 二次确认，用户取消时直接 return 中止流程。
- 需要实时更新的页面（CommandView、ConnectionsView）通过 `getHub()` 获取 SignalR Hub，订阅 `RealtimeChannels.*` 频道并使用 `RealtimeMethods.Receive*` 方法名接收推送，在 `onBeforeUnmount`/`onUnmounted` 中清理事件与 LeaveChannel。
- 时间字段统一通过本地 `fmtTime(utc)` 工具函数格式化，电压值通过 `fmtVolt` 按 ≥1000 换算为 kV 再显示。
- 样式上统一使用 `card` 容器 + `card-title` 标题 + `desc` 说明文字的布局约定，表单与表格均采用 Element Plus 的 `size="small"`、`border`、`stripe` 风格。
