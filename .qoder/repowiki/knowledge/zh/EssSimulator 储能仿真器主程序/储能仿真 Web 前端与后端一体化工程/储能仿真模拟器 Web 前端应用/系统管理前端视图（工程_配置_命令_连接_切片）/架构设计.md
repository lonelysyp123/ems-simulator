本模块由五个并列的 Vue 单文件组件构成，均位于 `Web/src/views/` 下，作为路由级页面被上层路由挂载：
- `ProjectManageView.vue`：通过 `getTopologyProjects` / `postTopologyProjectNew` / `postTopologyProjectOpen` / `deleteTopologyProject` 管理拓扑工程列表，并通过 `router.push('/topology')` 跳转到编辑器。
- `SystemConfigView.vue`：读取 `getSystemConfig` 展示工程模式开关与模板选择，调用 `postSystemApply` 提交并触发后端重启；使用 `lockSystem/unlockSystem/updateSystemProgress` 实现带进度条的重启流程，并通过轮询 `getHealth` 等待后端就绪后跳转 `/mainline`。
- `CommandView.vue`：提供命令输入框、快捷按钮与历史（`localStorage` 持久化），通过 `postCommand` / `postDpcTest` / `getAutoTest` 执行命令，并通过 SignalR Hub（`RealtimeChannels.CommandProgress` + `ReceiveCommandProgress`）实时接收测试进度。
- `ConnectionsView.vue`：拉取 `getConnections` 展示本机网络接口、Modbus 服务监听、协议链路状态与客户端连接，支持 `postLink` 切换在线/离线，并通过 SignalR `Connections` 频道实时刷新。
- `DroopSlicesView.vue`：以 2 秒定时器轮询 `getDroopSliceStatus` / `getDroopSlices`，配合 `setDroopSliceConfig` / `clearDroopSlice` 控制采集开关与清空，点击行通过 `getDroopSlice` 展开详情。
所有组件统一依赖 `@/services/api.js` 暴露的后端 API 封装，以及 `@/services/constants.js` 中的 SignalR 通道与方法名常量；不直接耦合后端 URL，仅通过 HTTP 与 SignalR 两种通信方式交互。
