- 每个快照类型以 `static class XxxSnapshotReader` 暴露只读静态方法，返回强类型 DTO，DTO 字段均为不可变或默认初始化的自动属性。
- 对可能缺失的模型变量统一通过 `GuiSimDataAccess.SafeGetDouble/SafeGetBool` 或 try-catch 包裹 `SimServer.GetExtIfVariableVal` 读取，失败时回退默认值而非抛错。
- BMS 簇数量解析采用 `ResolveClusterCount` 模式：优先从 `bms{unit}.BatteryStacks[0].Cluseter.Count` 动态读取，失败则回退到 `GuiSimDataAccess.GetClusterCount()`。
- 告警/门限项的中文标签、分类、等级、单位等元信息通过集中字典或基于名称后缀（Alarm/Fault/Protection/Prohibited）与关键词匹配的规则函数推导，避免硬编码分支散落在业务逻辑中。
- 对反射枚举的属性集合使用 `ConcurrentDictionary<Type, PropertyInfo[]>` 缓存，首次扫描后复用，避免重复反射开销。
