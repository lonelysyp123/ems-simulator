模块以 ASP.NET Core Minimal API 为入口，通过 `TopologyEndpoints.MapTopologyEndpoints` 暴露 `/api/topology/*` 路由，通过 `SystemConfigEndpoints.MapSystemConfigEndpoints` 暴露 `/api/system/*` 路由；两个端点类共用同一套 `EditionTopologyGate` 端点过滤器，基于 `EditionConfig.AllowTopologyEditor` 做产品档位门控。

内部按职责分层：
- 持久化层 `TopologyStore`：单例式文件存储，根目录固定为 `{ContentRoot}/configs/topology/`，分别维护 `project.json`（当前画布）、`projects/{id}.json`（命名工程）、`library/{id}.json`（设备库）、`runtime-mode.json`（运行模式开关与激活工程）、`generated/runtime-overlay.json`（运行时覆盖），所有读写通过 `_gate` 对象锁串行化，并使用自定义 `ObjectJsonConverter` 把 `Dictionary<string,object?>` 参数序列化为可读写标量/嵌套结构。
- 模板定义层 `TopologyTemplates`：静态注册电网、交流母线、三相断路器、变压器、电表、负载、EMU、光伏单元、BMS、直流母线等内置模板及其端口、参数、默认值，是连接关系与电气规则的基础元数据。
- 校验层 `TopologyValidator`：实现编辑级连线检查（`TryConnect`/`TryConnectBundle`）与保存级电气规则回放（`ValidateProjectForSave`），包含 AC/DC 域兼容、相位匹配、电压容差（2% pu）、AC 母线上侧仅允许电压源或串联断路器、电表统一 PT/CT 口必须接同相母线、直流极性约束、主断路器与并网点电表唯一性等规则，并通过 `RefreshAcBusEnergization` 自上而下推导母线带电状态。
- 转换层 `TopologyRuntimeConverter`：在应用前调用保存级校验，再将组态工程映射为 `TopologyRuntimeOverlay`（含 PCC、主变、PCS/BMS、负载、PV 单元、ESS 单元），供仿真运行时读取。
- 辅助层 `TopologyScaffold`：生成径向拓扑脚手架；`TopologyModels.cs` / `TopologyRuntimeModels.cs` 集中声明 DTO。

依赖方向单向：Endpoints → Store/Validator/Converter/Scaffold/Templates，Store 反向依赖 Templates 做端口合法性清理，Validator 依赖 Templates 做端口语义判断，Converter 依赖 Validator 保证先验正确性。
