- 端点使用 `MapGroup("/api/topology")` 或 `/api/system` 分组，并通过 `AddEndpointFilter(EditionTopologyGate)` 统一做产品档位门控，未授权返回 403。
- 所有 JSON 读写共享同一份 `JsonSerializerOptions`（驼峰命名、忽略 null、属性名大小写不敏感、注入 `ObjectJsonConverter`），确保前后端字段一致。
- `TopologyStore` 中每个 I/O 方法以 `lock (_gate)` 包裹，读/写成对出现，避免并发写入导致 project/library 损坏。
- 校验结果统一通过 `TopologyValidationResult` 表达，成功用 `Ok()` 工厂、失败用 `Fail(code, message, details?, problemNodeIds?)` 工厂构造，便于前端根据 code 定位问题。
- 模板通过 `TopologyTemplates` 静态注册表集中声明，新增设备类型只需追加一个 `BuildXxx()` 构建器，禁止在业务代码中硬编码模板 id。
- 保存路径采用“当前画布 + 命名工程”双轨：`SaveProject` 同时同步到 `projects/` 目录，删除命名工程时联动清理当前画布与激活运行模式引用。
