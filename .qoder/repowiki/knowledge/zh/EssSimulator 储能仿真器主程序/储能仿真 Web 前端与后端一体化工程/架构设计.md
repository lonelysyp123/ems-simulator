本模块以 ASP.NET Core Minimal API 作为统一后端，聚合 Topology（组态工程）、DroopSlices（下垂切片采集）与 SnapshotReaders（告警/电池/连接/门限快照）三个子模块提供的数据接口；RealtimeHub + ApiKeyAuthMiddleware 提供 SignalR 实时推送与可选鉴权，被各视图通过 @microsoft/signalr 消费。前端 src/ 通过 vite.config.js 将 /api 与 /hub 代理到后端，构建产物输出至 ../wwwroot，由同一进程托管静态资源，形成前后端同进程部署模式。Vue Router 按功能划分 views（MainLine/Battery/Topology/DroopSlicesView 等），services/api.js 统一发起 HTTP 请求，services/useRealtime.js 封装 SignalR 订阅，使所有视图共享同一套运行时契约。
