- 运行时配置以 POCO + IOptions<T> 形式在 Program 中集中 Configure/PostConfigure，再被各子模块消费。
- 长生命周期组件（EnergyStorageSystem、各类 DataServer、WebCommandExecutor 等）通过 AddSingleton 注册并由 AddHostedService 启动后台任务。
- 子模块之间通过 SimulatorHost.Instance 的全局键值存储进行松耦合通信，而非直接依赖注入。
- Modbus TCP 服务器按 BMS/EMU/PV/LC 四类设备分别分配端口段，启动时在 LogProtocolCreateInfo 中统一打印端口拓扑。
- Web 层统一通过 MapSimulatorEndpoints 扩展方法注册 REST/SignalR 端点，并以 API Key 中间件做鉴权。
