模块以命令模式组织：`ICommand` 定义统一接口（Name/Description/Execute），由 `CommandProcessor` 通过构造函数注入的 `IEnumerable<ICommand>` 注册并基于名称字典分发；每个命令实现一个独立类——`EssCommand`（esscmd 子命令集：setLoad/link/setGrid/setbms/pcs/setpv）、`BreakerCommand`、`DataPointChangeCommand`（dpc set/get，支持设备点与簇级 r*/rN 点名）、`DpcAutoTestCommand`（dpctest 从 autotest.json 加载用例并串行执行 dpc/sleep 步骤）。所有命令返回统一的 `CommandResult`（Success/Message/Data），便于 Web 层序列化为 JSON。命令通过 `SimulatorHost.Instance` 获取 `EnergyStorageSystem`、`ModbusSimServer` 等运行时对象，并通过 `SnapshotService.RequestImmediatePush()` 触发快照推送。除命令外，模块还提供 GUI 数据层：`GuiElectricalReader` 通过 `GuiSimDataAccess` 反射读取 ess/em 内部路径，组装 `MainLineSnapshot`（含 AcPhasorSnapshot、BusNodeSnapshot、PcsChannelSnapshot、UnitBranchSnapshot、MeterThreePhaseSnapshot 等只读记录结构）；`MainLineMetrics` 将字符串 metric（如 `unit.0.pcsA.activePowerKw`）解析为具体数值；`FatalSystemAlert` 提供进程级严重故障事件（SignalR 推送 + 倒计时退出）。依赖方向单向：命令 → 仿真核心（Core/EssDeviceSimModel/Web），GUI 读取层仅消费仿真状态，不反向修改模型。
