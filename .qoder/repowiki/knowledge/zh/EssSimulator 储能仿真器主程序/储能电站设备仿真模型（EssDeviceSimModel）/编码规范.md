- 所有物理设备通过 Interface 目录中的 IElectricalDevice/IPcsDevice/IBmsDevice 等接口暴露端口与控制能力，具体实现位于 Devices/Battery/Pv/Thermal 子域。
- 设备状态与配置集中在 Model 目录的 *Config/*State 类中，步进时由 DeviceStepContext 传递时间增量，避免跨域直接读写字段。
- 电气拓扑与潮流计算统一经由 NetworkTopologyBuilder 与 NetworkStepOrchestrator/RadialPowerSweepEngine 编排，禁止设备间直接互相调用求解逻辑。
- 跨域副作用（断路器、负载、PCS 黑启动、BMS-PCS 链路）一律通过 NetworkControlBridge 投影到 ElectricalNetwork，再同步回 Legacy 对象。
- 步进顺序固定为 PV 更新 → 电气步 → 热网络 → 耦合边 → 单元变同步 → 黑启动上下文刷新，新增物理过程需嵌入该流水线而非绕过。
