- 领域实体采用 `sealed class` + 只读 init 属性 + 可变 set 属性的组合，用于区分不可变配置字段与求解过程中可更新的运行态字段（如 `IsClosed`、`BusQuantity`）。
- 跨域数据通过带 `Domain` 字段的 `ElectricalPortSnapshot` 进行统一封装，并以 `FromAc` / `FromDc` 静态工厂构造，避免在调用方直接判断域类型。
- 三相量值统一以 `AcInternalQuantities` 作为内部表示，所有物理量换算（P/Q、星/三角、PT/CT）集中在 `AcQuantityConverter` 与 `MeterQuantityConverter` 中作为纯静态方法实现。
- 电气符号与单位约定（如 √3、容性无功为正）抽取到 `ElectricalConventions` 常量，由多个转换器共享以保证一致性。
- 设备控制与状态通过独立枚举（`DeviceCommandKind`、`ElectricalDeviceKind`、`PortKind`、`ThreePhaseConnection`）表达，而非字符串或魔法数。
- 配置到运行模型的转换集中在静态工厂类（如 `ElectricalTopologyFactory`、`MeterQuantityConverter.CreateTelemetry`），保持数据模型本身不含装配逻辑。
