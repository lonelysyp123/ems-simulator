- 每个配置类以 `public const string Section = "...";` 声明对应的 appsettings.json 节路径，便于外部配置绑定。
- 配置项优先使用带默认值的可空属性（如 `double? FixedCelsius`、`bool NoGui = false`），使 JSON 缺省字段自动回退到合理默认值。
- 复杂配置通过嵌套 POCO 组织（如 ThermalRuntimeConfig → ClimateConfig/BmsCabinetThermalConfig/ThermalProbeBiasesConfig），顶层 SimulatorConfig 暴露便捷计算属性（EffectiveEssUnitCount、UnitCount）。
- 产品档位通过 EditionConfig.Name 枚举（Community/Commercial/Custom）配合 ApplyPresets() 在启动时统一施加能力裁剪预设。
