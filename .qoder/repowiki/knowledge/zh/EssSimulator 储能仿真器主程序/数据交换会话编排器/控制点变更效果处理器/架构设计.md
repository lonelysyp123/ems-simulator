模块采用策略+注册表模式：IControlEffect.cs 定义统一接口（Id + OnControlChanged）及携带上下文数据的 ControlEffectContext；ControlEffectRegistry.cs 维护 ControlEffectId → IControlEffect 的字典并提供 Register/Dispatch 方法，作为唯一入口负责按 Id 路由调用；BmsControlEffects.cs 与 EmuControlEffects.cs 分别实现针对 BMS 和 EMU 的具体效果，内部通过解析 serverName（如 simBmsN / simEmuN）定位目标设备索引，再调用 EssSimModelApi 中的 ApplyForChannel、PcsMapper.ApplyEmuCommands、SetUnitBreakerClosed 等模型 API 驱动状态机，并在必要时触发遥测刷新与快照推送。依赖方向单向：具体 Effect → Model API / SimulatorHost，不反向依赖注册表。
