本模块由两个相互独立但运行时协同的数据层组成：
- `configs/`：应用级 JSON 配置。顶层按发行版提供多份 `*.appsettings.json`（社区版/演示版/定制版/商业版/充值版），通过键如 `Simulator.Edition.Name`、`Simulator.Runtime.NoGui` 等控制功能开关、网络端口、PCC/变压器/PES/EssUnits 参数；`configs/topology/` 采用自研 JSON 拓扑描述格式，`project.json` 以 `nodes`（含 `templateId` 如 grid/ac_bus/transformer/emu/bms 等）和 `edges`（fromNodeId/toPortId 连接图）定义完整储能电站拓扑，`library/` 存放可复用的节点模板片段，`projects/` 存放具体项目实例，`runtime-mode.json` 记录当前激活的工程 ID 与工程模式。
- `pointmaps/`：EMS 运行时读取的固定文件名 CSV（`emu.csv`、`em.csv`、`bms_bank.csv`、`bms_rack.csv`、`lc.csv`）按版本目录隔离，`common`（默认联调/商业发布）、`lc`（LocalControl，含 `lc.csv` 聚合寄存器）、`battery`（电芯级遥测，全量 `bms_rack`）三套版本各自带 `version.json` 声明 id/name/description；`_archive/` 保留历史旧版 CSV。发布流程通过 `scripts/sync-pointmaps-to-root.sh` 与 `publish-linux.sh`/`publish-windows.sh` 将选定版本的 CSV 复制到工作目录，商业发布固定使用 `common` 且不可覆盖。
依赖方向：运行时程序单向消费这些静态数据文件，模块内部无代码逻辑，仅作为数据源被上层仿真引擎加载。
