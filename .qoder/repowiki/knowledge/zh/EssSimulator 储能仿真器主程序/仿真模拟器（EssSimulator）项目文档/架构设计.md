本模块为纯文档目录，按读者角色与用途分层组织：根目录放置面向开发与运维的核心技术文档（`系统设计说明.md`、`B-S架构说明.md`、`appsettings.explained.md`、`指令详细说明.md`、`项目编译说明.md`），其中 `B-S架构说明.md` 描述了 ASP.NET Core + SignalR 后端与 Vue 3 SPA 前端的 B/S 架构、HTTP API 与实时推送通道；`appsettings.explained.md` 以强类型配置类为权威来源逐项解释 `appsettings.json` 字段。`marketing/` 子目录存放对外产品文案与演示脚本，`blog/` 子目录保留需求、设计、总结等过程笔记（注明部分仍描述旧控制台菜单）。`README.md` 作为文档索引，统一链接各文档并约定点表/端口/单元数以仓库 `appsettings.json` 为准、操作界面为浏览器 Web。
