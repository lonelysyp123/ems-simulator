# 仿真模拟器 — 用户手册

面向 EMS/BMS/PCS/光伏联调与测试人员。说明安装、启动、界面、Modbus 联调及常见问题；内部实现见 [系统设计说明](./系统设计说明.md)。

---

## 1. 产品简介

仿真模拟器在本地模拟电池、变流器、光伏单元、变压器、断路器及并网点电气行为，通过 **Modbus TCP** 提供与现场相近的遥测与控制接口，便于无真机或真机不足时完成主控联调。可组储能、光储或纯光伏工程。

- 对外名称：**仿真模拟器**
- 发布包为自包含程序，**无需单独安装 .NET 运行时**

## 3. 快速启动

### Windows

1. 解压整个文件夹（exe、配置、点表同目录）
2. 双击 `start.bat` 或运行 `EssSimulator.exe`
3. 等待终端出现协议就绪后，浏览器打开 **http://127.0.0.1:5050**（发布脚本通常会自动打开）

### Linux

```bash
chmod +x EssSimulator start.sh
./start.sh
```

### 开发环境

```bash
dotnet run --project EssSimulator.csproj
# 或一键前后端：./scripts/dev-up.sh
```

浏览器访问 `http://127.0.0.1:5050`（开发前端 HMR 为 `http://localhost:5173`）。

## 5. Modbus TCP 端口

在 `appsettings.json` → `Simulator.Protocol` 修改。常见默认：

| 设备 | 服务名 | 默认端口 | 点表 |
|------|--------|----------|------|
| 并网点电表 | simEm | 1500 | em.csv |
| BMS 第 N 路 | simBmsN | 1501+(N-1) | bms_bank.csv |
| EMU 第 U 单元 | simEmuU | 1601+(U-1) | emu.csv |
| LocalControl 第 U 路 | simLcU | 1701+(U-1) | lc.csv（`EnableLocalControl=true` 时） |
| 光伏 Logger 第 P 单元 | simPvP | 1801+(P-1) | pv_logger.csv |
| 光伏低压电表 第 P 单元 | simPvMeterP | 1901+(P-1) | pv_apm810.csv |

- 从站地址（Unit ID）一般为 **1**
- BMS 簇表从站：**1 + 簇序号**（见 `bms_rack.csv`）
- 光伏端口仅在工程含光伏单元（组态 overlay 的 `PvUnits`）时注册
- 默认监听 **127.0.0.1**；跨机联调需改绑定并放行防火墙；「协议端口」页可改端口并热重建，IP 白名单改完需**重启进程**

命令与 mbpoll 示例见 [指令详细说明](./指令详细说明.md)。

## 5.1 IEC 61850（MMS + 入向 GOOSE）

仿真器角色：**MMS 服务端 + GOOSE 订户**（设备侧）。外部工具（如 IEDScout）用发布端 ICD 发 GOOSE；仿真器**不发布**设备侧 GOOSE。

| 项 | 说明 |
|----|------|
| MMS | 默认端口从 `8102` 起（`BaseEmuIec61850Port`）；按台开关见「协议端口」页 / `configs/protocol-bindings.json` |
| 设备 ICD | `pointmaps/models/emu/iec61850/pcs.icd` |
| 外部发布 ICD | `pointmaps/models/emu/iec61850/ems_goose.icd` |
| 点映射 | `pointmaps/models/emu/iec61850/mapping.csv`（`Transport=goose` 为入向遥控点） |
| AppID | 基数默认 `0x2000`；PCS1 = `0x2001`（8193） |
| GoCbRef | 默认 `EMS_PCS01PCS/LLN0$GO$GoCB1`（可配置覆盖） |
| 网卡 | `EmuIec61850GooseInterface`；空则按 OS 默认。须与发布端同一二层网段（非按 IP 订阅） |

联调要点：发布端勿勾 Simulation/Test；改数据集后需 Update；macOS 需 BPF 权限。Web 页「IEC 61850」可看入向报文与解码；连接页仅摘要。配置项见 [appsettings 字段说明](./appsettings.explained.md)。

### 6.1 设备型号与点位表选择（系统配置页）

不同设备型号使用不同的 Modbus 点位表。系统配置页「设备型号与点位表」卡片按设备类型
（BMS / EMU / EM / LocalControl / PV）列出可选型号，选择后点「确认并重新初始化」，
选型写入 `configs/topology/device-models.json`，后端重启后按选中型号的点表重建 Modbus 服务。

- 型号点表位于 `pointmaps/models/{设备类型}/{型号}/`，新增型号只需放入点表文件与 `model.json`，无需改代码。
- 未选型的设备类型按 `pointmaps/models/{类型}/standard/` 解析。
- 组态保存时不再按 PCS 台数切换 LocalControl 点表（`unit_5.5MW` / `unit_10MW` 片段始终拼装进 LC）；EMU 保持单元直控点表。
- 中压 LC 点表含 ModelSim：遥测从仿真模型采集并写入 LC Modbus；基础 LC 仍按点名桥接 EMU。

### 6.2 组态编辑（拓扑画布）

组态画布上拖入设备、拉线完成站侧接线；EMU 储能单元为**虚拟节点**：

- **EMU 储能单元**：拖入后不在画布显示图形，由左侧「EMU 储能单元」列表面板管理
  （新增 / 重命名 / 删除 / 改单元变参数）；面板同时展示该 EMU 绑定的断路器 / 电表（未绑定显示「未绑定」）；
  删除 EMU 会自动解除归属它的 PCS、断路器与电表，并一并删除其下属分组。
- **PCS 变流器支路**：独立设备节点（一条支路；两条支路组成一台 PCS），上接三相 AC（35 kV 母线）、下接直流（BMS/DC 母线）；
  参数「所属 EMU 储能单元」下拉框选择归属的 EMU，选择后该支路计入该 EMU。左侧 EMU 树计数为「支路×N」（N 为 `pcs` 节点数，不影响 5.5/10MW 点表选型）。
- **EMU 分组（可选）**：部分场站的 EMU 内部分多个 group（如 2 group×2~4 支路），
  可用「EMU 分组」虚拟模板建模：分组同样不在画布显示图形，通过参数选择所属 EMU，
  并在左侧列表面板以「EMU → 分组 → 设备」两级嵌套展示。PCS / 断路器 / 电表另可通过可选参数
  「所属 EMU 分组」归入分组（仅能选与自身同 EMU 的分组；切换所属 EMU 时自动清空分组归属）。
  分组为纯协议层：不影响电气求解与主接线 / 3D 渲染，仅影响 EMU 协议视图与中压 LC 点表的分组聚合遥测；
  不建分组时行为与旧版扁平构成完全一致。
- **断路器 / 电表绑定**：三相断路器、三相电表同样通过参数「所属 EMU 储能单元」归入 EMU，
  绑定**可选**，且每个 EMU 至多各绑 1 台。绑定后：
  - 电站概览中该断路器 / 电表以真实节点身份画入 EMU 虚线框（虚线框包裹整单元：
    断路器 → 单元变 → 690 母线 → PCS → DC 母线 → BMS）；未绑定则沿用合成符号或不画。
  - 数字孪生（3D）不引入 EMU 概念，按组态逐设备绘制：绑定的断路器 / 电表、每台 PCS / BMS
    各自独立出模型；未绑定的设备不画。
- **保存校验**：每台 PCS 必须选择有效的所属 EMU；断路器 / 电表已选 emuId 时必须指向存在的 EMU，
  且同一 EMU 下断路器 / 电表各至多 1 台（超出报 `EMU_BREAKER_DUPLICATE` / `EMU_METER_DUPLICATE`）；
  已选「所属 EMU 分组」的设备：分组须存在（否则报 `GROUP_UNASSIGNED`），且分组所属 EMU 须与
  设备自身所属 EMU 一致（否则报 `GROUP_EMU_MISMATCH`）；每个分组下断路器至多 1 台
  （超出报 `EMU_GROUP_BREAKER_DUPLICATE`），电表允许多台；
  工程至少需要一个含 PCS 的 EMU 或光伏单元。
- **应用到仿真**：按 EMU 分组生成储能单元，每台 PCS 沿其直流连线配 1 台 BMS（1:1 对齐）；
  绑定的断路器 / 电表记录为单元的 `HasUnitBreaker` / `HasUnitMeter` 构成。
  EMU 内有分组节点时，PCS / 断路器 / 电表按分组归集生成 `Groups`（EMU → group → PCS 支路），
  未选分组的 PCS 归入合成「直挂」组；无分组时保持扁平构成。
- **点表绑定门控**：EMU（simEmu）与 LocalControl（simLc）点表的 ModelSim 绑定只能指向机组内
  实际存在的设备模型：`PcsList[i]` 路径要求 i 小于该机组 PCS 台数，`ElectricityMeter` 路径要求
  机组绑定电表，`Emu.PowerOnOff`（单元高压断路器开合）要求机组绑定断路器；找不到对应设备的点位
  在目录编译期剔除，按未绑定点位处理（寄存器仅维持点表默认值，遥测不刷新、控制写入不生效）。
  分组构成另支持 `Groups[g].PcsList[i]` / `Groups[g].Breaker` / `Transformers[k]` / `Breaker.*`
  等分层路径（语法与门控条件见 `pointmaps/README.md`）。
  无组态 overlay 的纯 appsettings 部署不门控，行为与旧版一致。
- **光伏单元**（模板 `pv_unit`）：复合节点，上方三相 AC 接入 35 kV 集电母线；内部为箱变 + 多台组串逆变器 + 方阵 A/B。默认 16 台 320 kW / 690 V 逆变器、组件 `TSM-NEG21C.20Q`；参数可改逆变器台数、组件型号、投运年限、地面反照率等。`TopologyRuntimeConverter` 展开为 overlay `PvUnits`，运行时挂 35 kV 母线送电。主接线 / 3D 按单元内部图例展开（逆变器、方阵），不把整台当单一符号。
- 向导（新建工程）按 **EMU 数 + 光伏单元数** 生成径向骨架（各 0–20，至少一个大于 0）；每个 EMU 默认含 2 台 PCS。可建纯光伏工程（EMU=0）。

注意：旧版以 EMU 为连线节点的工程不再兼容，需按新模型重建。

## 7. 典型联调顺序

储能单元：

```text
dpc simEmu1.yx0 set 1          # 单元高压合闸
esscmd setbms1 power on        # BMS 直流并网
dpc simEmu1.yx3 set 1          # PCS1 启动
dpc simEmu1.yt0 set 1000       # 有功 100 kW（Scale 10）
```

光伏单元（工程含 `PvUnits` 时；内部控制也可用 `esscmd setpv1 …`，不依赖点表）：

```text
esscmd setpv1 run on
esscmd setpv1 power 100        # 限发 100 kW
esscmd setpv1 array A angle 90 # 方阵 A 正对（1000 W/㎡）
```

外部 EMS 等价写点：`dpc simPv1.yt4 set 1`（启停）、`yt5`（有功，Scale 10）、`yt7`（无功，Scale 10）。

在主接线查看 **P设 / P实**（储能）或光伏实发，或用 mbpoll 读对应反馈点。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| Modbus 连不上 | 等协议就绪；查端口、防火墙、IP 绑定；若「协议端口」白名单非空，只允许名单内 IP（NAT 后填仿真器看到的对端地址），改名单后需重启 |
| GOOSE 订不到 | 查网卡名与发布端同二层；AppID/GoCbRef；勿勾 Test；macOS BPF |
| IEC 61850 MMS 连不上 | 查「协议端口」是否开启、端口 8102 起是否冲突；Windows 需 `iec61850.dll` 与 exe 同目录 |
| PCS 启停无效 | 查 yx0 合闸、BMS 并网、`esscmd setbms1 power on` |
| P实 为 0 | 确认 PCS 运行且并网；注意 Scale（100 kW → 写 1000） |
| 光伏无出力 | 确认工程含 `PvUnits`、`setpvN run on`、方阵入射角（90=满辐照）；主断分闸后并网出力为 0 |
| dpc 功率差 10 倍 | 控制点写 **原始寄存器值**，非工程 kW |
| link 后 SOH 等为 0 | 重连后会刷新；仍异常则重启或查 [指令说明](./指令详细说明.md) |
| 改单元数无法启动 | 检查 JSON 语法、EssUnits / 组态 overlay 的储能与光伏单元、端口冲突 |
