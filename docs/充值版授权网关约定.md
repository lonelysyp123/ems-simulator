# 充值版授权 / 网关约定

> **现状**：标准产品档位为社区版 / 商业版 / 定制版 / 演示版。发布脚本里旧名「充值版」会**映射为商业版**。本文仍适用于「仓外网关托管仿真实例」的接入方。

本文约定：**仿真进程本身不计费**；时长、会话、写控权限由**仓外授权服务或网关**控制。  
仿真侧提供可被编排的健康检查、链路开关与命令入口，便于运维侧落地。

相关文档：[产品分档与交付边界](./产品分档与交付边界.md)、[B-S 架构说明](./B-S架构说明.md)、[指令详细说明](./指令详细说明.md)。

## 1. 职责划分

| 角色 | 职责 | 不负责 |
|------|------|--------|
| **仿真进程（本仓库）** | 按配置跑拓扑；暴露 Modbus / HTTP；响应链路 on/off | 用户账号、余额、套餐、JWT 签发 |
| **授权服务（仓外）** | 登录、充值、会话时长、是否允许写控 | 电气模型与点表语义 |
| **接入网关（仓外）** | TLS、鉴权、限流、按会话转发到实例；到期切断 | 改仿真内部物理量 |

推荐部署形态：

```
用户/EMS ──► 授权网关（鉴权+计时）──► 仿真实例（充值版：0.0.0.0 + NoGui）
                │
                └──► 到期/欠费时：拒绝新连接，并对已分配实例执行「链路全 off」或停实例
```

## 2. 仿真侧已有能力（可被网关调用）

充值版默认启用 `Simulator.Web`（模板端口 **5050**，`StaticFiles=false`），并建议 **`ApiKeyEnabled=true`**。  
密钥**不要**写入公开配置：用环境变量注入，例如：

```bash
export Simulator__Web__ApiKey='replace-me'
```

网关调用受保护接口时携带：

```http
X-Api-Key: replace-me
```

或 `Authorization: Bearer replace-me`。

`GET /api/health` **豁免**鉴权，供探活。其余 `/api/*` 在启用 ApiKey 且未提供正确密钥时返回 401；已启用但未配置密钥时返回 503。

下列接口在 ApiKey 关闭时无内建鉴权；公网必须只对网关开放，或开启 ApiKey / 由网关鉴权后再转发。

| 能力 | 调用方式 | 用途 |
|------|----------|------|
| 健康检查 | `GET /api/health`（免 Key） | 探活、就绪后再把用户导流到该实例 |
| 连接/链路快照 | `GET /api/connections`（需 Key） | 运维看板、判断 Modbus 是否在听 |
| 单路链路开关 | `POST /api/link/{target}/{state}`（需 Key） | `target=em\|bmsN\|pcsN`，`state=on\|off` |
| 通用命令 | `POST /api/command` body `{"input":"esscmd link status"}`（需 Key） | 批量编排、与 TUI 同语义 |
| Modbus 端口表 | `GET /api/protocol`（需 Key） | 网关动态开端口映射 |

链路关闭语义（`esscmd link … off` / `SetOnline(false)`）：**停止该设备 Modbus 监听**，外部客户端无法再连；`on` 后恢复监听并刷新遥测 Shadow。

示例（网关在会话到期时切断对外通道）：

```bash
# 关闭并网点电表与各单元（按实际单元数循环）
curl -s -H "X-Api-Key: $Simulator__Web__ApiKey" -X POST "http://127.0.0.1:5050/api/link/em/off"
curl -s -H "X-Api-Key: $Simulator__Web__ApiKey" -X POST "http://127.0.0.1:5050/api/link/bms1/off"
curl -s -H "X-Api-Key: $Simulator__Web__ApiKey" -X POST "http://127.0.0.1:5050/api/link/pcs1/off"

# 或
curl -s -H "X-Api-Key: $Simulator__Web__ApiKey" -X POST "http://127.0.0.1:5050/api/command" \
  -H 'Content-Type: application/json' \
  -d '{"input":"esscmd link em off"}'
```

仅「只读体验、禁止写控」时：网关侧应对 **FunctionCode 5/6（写）** 做拒绝或丢弃，读（3/4）可放行；仿真进程无需改代码。

## 3. 建议的会话状态机（仓外实现）

```
Created → Provisioned（实例就绪，health ok）
       → Active（用户已鉴权，链路 on，开始计时）
       → Suspended（欠费/暂停：链路 off，保留实例）
       → Terminated（释放实例或停进程）
```

| 事件 | 网关动作 | 仿真侧期望 |
|------|----------|------------|
| 开通体验 | 分配端口/实例，鉴权通过后允许 TCP/HTTP | `GET /api/health` 就绪；按需 `link … on` |
| 时长耗尽 | 拒绝新 Modbus/HTTP；调用全链路 `off` | 监听关闭，已有连接断开 |
| 续费成功 | 恢复转发；`link … on` | 监听恢复 |
| 管理员强制下线 | 同「时长耗尽」 | 同左 |

**本仓库不规定**具体的 Token 格式、回调 URL 或数据库表结构；交付时由运维侧给出实现，只要满足上表语义即可。

## 4. 安全基线（充值版）

1. 进程监听 `0.0.0.0` 仅用于容器/内网；**公网入口必须经网关**。  
2. `/api/*` 与 Modbus 端口不对公网直连；或网关做 mTLS / 内网 ACL。充值版务必开启 `ApiKeyEnabled` 并用环境变量注入密钥。  
3. 写控（线圈/保持寄存器写、以及 `POST /api/command`）默认仅对「已付费且未到期」会话开放。  
4. 日志中勿打印用户充值凭证与 `ApiKey`；仿真日志只记录设备与链路事件。

---

## 5. 与配置模板的关系

`configs/充值版.appsettings.json`：

- `BindAddress` /（Web）`HttpBaseUrl`: `0.0.0.0` — 供同主机网关或 sidecar 接入  
- `Simulator.Web.ApiKeyEnabled: true`，`ApiKey` 留空并由 `Simulator__Web__ApiKey` 注入  

计费开关**不要**写进该文件；改拓扑不会改变授权结论。

## 6. 验收清单（联调授权时）

- [ ] 未鉴权访问网关 → 无法到达仿真 Modbus/API  
- [ ] 鉴权通过 → `health` 成功，可读写约定端口  
- [ ] 无 `X-Api-Key` 调用 `/api/command` 或 `/api/link` → 401（充值版）  
- [ ] 模拟到期 → 新连接失败，且 `link status` 显示 off 或端口不可达  
- [ ] 续费 → 链路恢复，EMS 可重新建立会话  
- [ ] 只读套餐 → 写寄存器被网关拒绝，读正常
