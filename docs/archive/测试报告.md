## 2. 本次测试范围

| 编号 | 测试项 | 触发方式 | 监控方式 | 验收标准 |
|------|--------|----------|----------|----------|
| TC-R01 | BMS bank 一键并网（**yc133**） | 脚本写 FC6 寄存器 | mbpoll 读 **同一点** | ΔT ≤ 700 ms |
| TC-R02 | EMU 高压断路器（**highvoltagebreakeronoff**） | 脚本写线圈 | mbpoll 读 **同一点** | ΔT ≤ 700 ms |
| TC-R03 | BMS rack 总电压过压门限（**yc1326**） | 脚本写 FC6 | mbpoll 读 **同一点** rack | ΔT ≤ 700 ms |
| TC-R04 | EMU 功率因数设定（**param57**） | 脚本写 FC6 | mbpoll 读 **同一点** | ΔT ≤ 700 ms |
| TC-R05 | PCS1 启动（**pcs1_startstop→param25**） | mbpoll 写启停线圈 | mbpoll 读 **运行状态 param25** | ΔT_status ≤ 700 ms |
| TC-R06 | PCS1 停机（**pcs1_startstop→param25**） | mbpoll 写启停线圈 | mbpoll 读 **运行状态 param25** | ΔT_status ≤ 700 ms |

**计时规则**

| 符号 | 含义 |
|------|------|
| T0 | GUI「命令输入」中 dpc 回显时间戳（`HH:mm:ss.fff`） |
| T1 | mbpoll 监控终端**首次**读到与预期一致的值（线圈 0/1 或寄存器 raw 值） |
| ΔT | T1 − T0（含约 ±50 ms 轮询误差） |

**同点原则**（TC-R01～R04）：触发点位与 mbpoll 监控点位必须一致（改哪个点、读哪个点），不跨 bank/rack 做联动观测。

**控制→反馈原则**（TC-R05～R06）：mbpoll 写 **pcs1_startstop**，监控 **param25**（`OperationStatus`）。v2.0.0 经 **DataExchange** 控制管道 + **EmuPcsControlEffect** 立即 `ApplyEmuCommands`，遥测由 **EmuTelemetryIntervalMs(100ms)** 刷新。

| 符号 | 含义 |
|------|------|
| ΔT_coil | T0 写线圈后，pcs1_startstop 读回一致 |
| ΔT_status | T0 写线圈后，param25 首次达预期状态码 |

### 4.5 TC-R05/R06：PCS1 启停与运行状态

| 项 | 控制（写） | 反馈（读） |
|----|------------|------------|
| 点名 | **pcs1_startstop** | **param25** |
| FC / 地址 | 5 / **5303** | 4 / **25333** |
| 端口 / 从站 | 1601 / 1 | 1601 / 1 |
| 有功预设 | **param55** @ **5300** raw=500 | — |
| 启动期望 | 写 1 | param25 ∈ **{1,3,4}** |
| 停机期望 | 写 0 | param25 = **0** |

**param25 状态码**：0 停机 · 1 待机 · 2 故障 · 3 充电 · 4 放电

```bash
while true; do
  date '+%H:%M:%S.%3N'
  echo -n "start="; mbpoll -0 -t 0 -a 1 -r 5303 -c 1 -p 1601 -1 -q 127.0.0.1
  echo -n " status="; mbpoll -0 -t 3 -a 1 -r 25333 -c 1 -p 1601 -1 -q 127.0.0.1
  sleep 0.05
done
```

**测试前条件**：单元 **highvoltagebreakeronoff=1**、BMS1 **并网**、启动前 param25 ≠ 2。

**理论路径**：mbpoll 写 pcs1_startstop → DataExchange 控制(100ms) → **EmuPcsControlEffect** → PCS 模型变位 → PcsDataServer(100ms) → **EMU 遥测(100ms)** → param25 可读。**ΔT_status 预期 ≤ 300 ms**。

#### 用例定义

| 项 | 内容 |
|----|------|
| 目的 | 测量触发 **bank yx5** 后，**同一点位**在 Modbus 上反映的延迟 |

| 预期 ΔT | ≤ **700 ms** |

#### 触发与复位

| 项 | 内容 |
|----|------|
| dpc 置位 | `dpc simBms1.yx5 set 1` |
| dpc 复位 | `dpc simBms1.yx5 set 0` |

| 脚本代跑 | `python3 scripts/test/perf/run_tc_r01.py`（mbpoll 写 addr 1005，监控同址） |

#### 操作步骤

1. 终端 B 启动 4.1 节 **yx5** 监控循环，确认初始值为 **0**。
2. GUI →「命令输入」，或运行代跑脚本。
3. 执行 `dpc simBms1.yx5 set 1`（或脚本写线圈），记录 **T0**。
4. 观察终端 B，记录 yx5 首次变为 **1** 的 **T1**，计算 **ΔT = T1 − T0**。
5. 执行复位 `dpc simBms1.yx5 set 0`，记录 yx5 回 **0** 的 ΔT（可选）。

## 8. 附录

### 8.1 备用 / 故障排查

**TC-R01：yx5 无变位或 ΔT 过大**

- 确认监控与触发均为 **slave 1 / addr 1005**，勿误读 rack 从站。
- dpc 路径理论上限约 **500 ms**（DataWorker）；mbpoll 写线圈路径通常 **<100 ms**。
- 若 dpc 无回显，检查 GUI 是否已进入「命令输入」（主界面按 `C` 或 `:`）。

**TC-R02：yx1 无变位或 dpc 无效**

- 确认监控与触发均为 **slave 1 / addr 1001 / 端口 1601**。
- yx1 **ModelSim=0**，优先用 **mbpoll 写线圈**或脚本 `run_tc_r02.py` 测 Modbus 层延迟。
- 若需测绑定模型的断路器点位，可另立用例（如 yx0 高压断路器），须遵守同点原则，不与 yx1 混测。

**TC-R03：yt4 无变位**

- 确认 **slave 2 / addr 40004 / 端口 1501**，mbpoll 读写的 `-t` 均为 **4**（FC6 保持寄存器）。
- rack 从站号 = 簇号 + 1（簇 0 → slave 2）。

**TC-R04：yt2 无变位**

- 确认 **slave 1 / addr 40002 / 端口 1601**，`-t 4` 读写。
- raw 值需按 Scale 1000 换算（0.950 → 950）。

**TC-R05/R06：启动无响应或 yc44=2**

- 确认 **yx0=1**（单元高压合闸）、并网点有网；必要时写 **yt0** 有功设定。
- 启动后若 **yx3 被清 0**，为联锁保护（无网/单元高压分/黑启动条件不满足），非 Modbus 延迟问题。
- **yc44=2** 表示故障态，需先排除告警再测启动。
- 主验收看 **yc44（OperationStatus）**，不是 yx3 线圈读回。
