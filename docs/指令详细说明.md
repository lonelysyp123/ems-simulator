# 指令详细说明

仿真模拟器控制台命令与 Modbus 联调要点。在 GUI **命令输入** 或主接线 **临时命令**（`:` / `C`）中输入。

设备名（Modbus 服务名）：`simEmu1`、`simBms1`、`simEm`、`simPv1`、`simPvMeter1` 等，与 `appsettings.json` 端口对应。光伏从站仅在工程含 `PvUnits` 时存在。

---

## 1. 通用约定

### 1.1 Scale 与原始值

点表 CSV 的 **Scale** 列定义：工程值 = 原始寄存器值 ÷ Scale。

| 操作 | 写入内容 |
|------|----------|
| `dpc` / mbpoll 写**控制点** | **原始寄存器值** |
| 读遥测 | 原始值，按 Scale 换算为工程值 |

例：`yt0` Scale=10，有功 100 kW → 写 **1000**。

### 1.2 控制点 vs 遥测点

| 类型 | CSV FunctionCode | dpc set 行为 |
|------|------------------|--------------|
| **控制点** | 5 / 6 / 16 | 走 DataExchange 控制管道，触发启停、并网等副作用 |
| **遥测点** | 3 / 4 | 直接写寄存器；若 `ModelSim` 绑定模型，**下一遥测周期会被覆盖** |

### 1.3 不可改 / 不宜改的点位

`ModelSim` 为 `0` 或未绑定路径的点：

- **无仿真数据源**，写值不反映物理过程；
- 部分点仅为占位，读值固定为 0 或 CSV 默认。

`ModelSim` 已绑定且由模型周期刷新的遥测点：

- `dpc set` 可短暂改寄存器，但 **100~500 ms 内** 会被 `DataExchange` 遥测管道覆盖。

详见下文 §5 示例。

## 2. dpc — 按点名读写

```text
dpc <设备>.<点名> get
dpc <设备>.<点名> set <值>
dpc help
```

### 2.1 PCS / EMU（simEmu1，端口见配置，常见 1601）

**高压合闸**

```text
dpc simEmu1.yx0 set 1
```

| 结果 |
|------|
| 成功：回显带时间戳的写入确认；主接线单元高压合；`yx0` 读回 1 |
| 失败：`找不到对应的 Modbus 设备`（服务未就绪）；`找不到对应数据点`（点名错误） |

**PCS1 启停**

```text
dpc simEmu1.yx3 set 1    # 运行
dpc simEmu1.yx3 set 0    # 停机
```

| 结果 |
|------|
| 成功：触发 `PcsApplyCommands`；`yc44` 运行状态变为 2（待机）/4（充）/5（放）等 |
| 无效：主断分、BMS 未并网时 PCS 可能仍待机或 P实=0 |

**有功 / 无功设定**（控制点，Scale 10）

```text
dpc simEmu1.yt0 set 1000     # 100 kW
dpc simEmu1.yt1 set 200       # 20 kvar
```

| 结果 |
|------|
| 成功：主接线 **P设** 更新；并网且 PCS 运行后 **P实** 爬坡趋近设定 |
| 读回：`dpc simEmu1.yc27 get` 有功反馈（int32，Scale 10） |

**读运行状态**

```text
dpc simEmu1.yc44 get
```

| 值 | 含义 |
|----|------|
| 1 | 停机 |
| 2 | 待机 |
| 4 | 充电运行 |
| 5 | 放电运行 |
| 6 | 未知（存在告警汇总） |

### 2.2 BMS（simBms1，常见端口 1501）

**一键并网 / 离网**（`yt0`，FC6，脉冲）

```text
dpc simBms1.yt0 set 1    # 并网
dpc simBms1.yt0 set 2    # 离网
```

| 结果 |
|------|
| 写 1 成功：`yc0`（GridConnectStatus）→ 2；`yc45` 在网簇数 → 12 |
| 写 2 成功：直流链路断开；`yc45` → 0 |
| 并网失败：`yc0` → 3（如存在三级报警） |

**读 SOC**

```text
dpc simBms1.yc11 get
```

工程 SOC ≈ 返回值 / 1000（Scale 1000）。

**堆级告警位**（`yx5` 等，FC5，可写）

```text
dpc simBms1.yx21 set 1    # 簇过压二级报警
dpc simBms1.yx21 set 0
```

写入 `SystemAlarms`，EMS 可读 yx 与汇总字。

### 2.3 电表（simEm，端口 1500）

```text
dpc simEm.yc19 get
dpc simEm.yc19 set 49.95
```

`yc19` 若绑定 PCC 频率/电压等，set 行为取决于 `ModelSim`；未绑定点 set 仅改寄存器缓存。

### 2.4 光伏 Logger（simPv1，常见端口 1801）

工程含 `PvUnits` 时才有从站。内部控制优先用 `esscmd setpv1`（见 §3.5）；外部 EMS 写点：

```text
dpc simPv1.yt4 set 1      # 子阵列启停 On
dpc simPv1.yt4 set 0      # Off
dpc simPv1.yt5 set 1000   # 有功 100 kW（Scale 10）
dpc simPv1.yt7 set 200    # 无功 20 kvar（Scale 10，可负）
```

低压电表：`simPvMeter1`（常见 1901），点表 `pv_apm810.csv`。

## 3. esscmd — 仿真操控

```text
esscmd help
```

### 3.1 站用负荷

```text
esscmd setLoad activePower -500     # kW，仅允许 ≤0（负=消耗有功）
esscmd setLoad reactivePower -100   # kvar，可正可负
```

| 结果 |
|------|
| `执行成功: 负载 activePower = 500`；35 kV 侧负荷模型更新 |

### 3.2 BMS 物理并网（非通讯 link）

```text
esscmd setbms1 power on
esscmd setbms1 power off
```

| 命令 | 结果 |
|------|------|
| `on` | `GridConnectStatus→2`，`IsPcsLinked=true`，PCS 直流侧有压 |
| `off` | 链路断开，`GridConnectStatus→0` |

### 3.2.0 BMS 热设 SOC

```text
esscmd setbms1 soc 0.55
esscmd setbms1 soc 55
```

| 参数 | 说明 |
|------|------|
| `0~1` | 标幺 SOC |
| `>1` 且 `≤100` | 按百分比（`55` = 55%） |

| 条件 | 结果 |
|------|------|
| 该 BMS **待机**（堆电流为 0） | 立即写透全部电芯并刷新堆汇总 |
| 仍在充/放电 | 拒绝，提示先待机后再修改 SOC |

主接线 BMS 框「SOC(%)」设定走同一命令。

### 3.2.1 BMS 故障清除

```text
esscmd bms1 fault clear
```

| 条件 | 结果 |
|------|------|
| 系统**待机**（堆电流为 0） | 清除充放电方向一级/二级/三级故障，Rack 故障态恢复，可再 `setbms1 power on` |
| 仍在充/放电 | 拒绝，提示先待机 |

说明：
- 绝缘、压差等非充放电方向故障不在此指令清除范围内；
- **清除是一次性复位**：再次进入充/放电且仍超对应阈值时，会按当前值直接落入对应等级并重新触发；
- **等级处置**：三级故障（或 Rack `IsFault≠0`）→ 自动 BMS 下电（断开 PCS 链路）；一级保护/二级告警仅置位，不自动离网。

### 3.3 协议链路（Modbus TCP 启停）

```text
esscmd link bms1 off
esscmd link bms1 on
esscmd link pcs1 off
esscmd link em off
esscmd link em on
esscmd link pv1 off
esscmd link pv1 on
esscmd link pvMeter1 off
esscmd link status
esscmd link status bms1
esscmd link status em
esscmd link status pv1
```

| 命令 | 结果 |
|------|------|
| `link bms1 off` | 关闭 simBms1 监听，EMS **连不上**；仿真内部仍运行 |
| `link bms1 on` | 恢复监听；重连后遥测 Shadow 刷新，SOH 等恢复正常 |
| `link pcs1 off` | 关闭 **整个 EMU 单元** Modbus（同单元 2 台 PCS 共用 simEmuN） |
| `link em off` | 关闭 simEm 监听，EMS **无法读取并网点电表**；仿真内部仍运行 |
| `link em on` | 恢复电表 Modbus 监听；重连后遥测 Shadow 刷新 |
| `link pv1 off` / `on` | 关闭/恢复 simPv1（光伏 Logger） |
| `link pvMeter1 off` / `on` | 关闭/恢复 simPvMeter1（光伏低压电表） |

**注意**：`link` 模拟通讯中断，**不等于** `setbms power off` 物理离网。

### 3.4 PCS 直控（不依赖点表点位）

```text
esscmd pcs1 start
esscmd pcs1 stop
esscmd pcs1 power 100        # 有功设定 100 kW（无功保留现值）
esscmd pcs1 reactive 20      # 无功设定 20 kvar（有功保留现值）
```

| 结果 |
|------|
| 直接作用于仿真设备（`PcsDevice`）与 EMU 镜像 DTO，复用外部写点同一套联锁链（主断/单元断路器/黑启动/故障锁存） |
| 点表存在启停位/设定寄存器时，状态由反馈/遥测管道自动冒泡回 Modbus；**点位缺失时安全跳过，不报「找不到对应数据点」** |
| 故障跳闸后启停位自动撤回；再次 `stop`（写 0）清除故障锁存，与 EMS 停机/复归语义一致 |

说明：PCS 全局编号跨单元连续（单元 1 为 pcs1/pcs2，单元 2 为 pcs3/pcs4，以此类推）。

### 3.5 光伏单元直控（不依赖点表点位）

```text
esscmd setpv1 run on
esscmd setpv1 run off
esscmd setpv1 power 100      # 限发有功 100 kW（超额定按额定 clamp）
esscmd setpv1 reactive 20    # 无功设定，可正可负
esscmd setpv1 array A temperature 35   # 方阵 A 环境温度 ℃（电池温度由 NOCT 估算）
esscmd setpv1 array B angle 90         # 入射角：90=正对 1000 W/㎡
esscmd setpv1 array A albedo 0.2       # 地面反照率 0~1；G_rear = 反照率 × 平面辐照
```

| 结果 |
|------|
| 直驱 `PvLogger` → `PvUnitDevice`（启停、限功率下发各逆变器）；点表存在对应绑定时自动冒泡 |
| 方阵气候直驱 `PvArrayClimate`（A/B 独立）：环境温度、入射角、反照率；下一步按 MPPT 重算可发功率 |

> 内部控制（esscmd / 电站概览按钮 / `/api/breaker/unit`）均已改为直控仿真设备，不再写点表；`dpc` / `dpctest` 仍是通用点表工具，外部 EMS 写 Modbus 的下行路径不受影响。

## 4. breaker — 主断路器

```text
breaker set true     # 220 kV 主断合闸
breaker set false    # 分闸
```

| 结果 |
|------|
| `执行成功`；主接线主网带电状态变化；分闸后并网 PCS 可能停机或转离网逻辑 |

## 5. dpctest — 自动化脚本

```text
dpctest list
dpctest <测试名>
dpctest help
```

配置：`autotest.json`

```json
{
  "tests": [{
    "name": "ramp_test",
    "steps": [
      "dpc simEm.yc19 set 49.95",
      "sleep(10000)",
      "dpc simEm.yc19 set 49.9"
    ]
  }]
}
```

**`sleep(N)` 单位为毫秒**：`sleep(100)` = 100 ms，`sleep(10000)` = 10 s。

## 6. 不可修改点位示例

以下基于当前 `emu.csv`（`ModelSim` 为 `0`）。

### 6.1 占位遥测 — 写后无物理意义

```text
dpc simEmu1.yc45 set 1250
dpc simEmu1.yc45 get
```

`yc45`「单元1当前告警」未绑定模型（`ModelSim` 为 `0`），**dpc 改 yc45 不会改变 PCS 告警状态**，EMS 可能读到写入值，但与仿真行为不一致。

**可能结果**：get 短暂为 1250；下一周期若被其他逻辑刷新则变回；主接线/PCS 行为不变。

### 6.2 模型绑定遥测 — 写后被覆盖

```text
dpc simEmu1.yc27 set 9999
```

`yc27` 绑定 `PcsList[0].ActivePower`，由 `MapPcsState` 每 100 ms 刷新。

**可能结果**：set 成功；约 100 ms 内 get 回到真实有功功率（如 0 或爬坡中值）。

### 6.3 未映射点

```text
dpc simEmu1.yx99 set 1
```

**结果**：`指定设备找不到对应数据点`

### 6.4 只读输入寄存器（FC4）

对纯 FC4 点用 mbpoll 写会失败；应用 `dpc set` 仅当该点同时出现在控制映射中。堆级只读遥测应使用 **get** 或 mbpoll 读。

### 6.5 黑启动反馈勿用 dpc 强写

`BlackStartEnabled` 等由 EMS 下发，仿真会在 `MapPcsState` 中保护，避免用遥测 dpc 覆盖命令态。

## 7. mbpoll 快速参考

须先查 CSV 的 **FunctionCode** 再选 `-t`（勿默认 `-t 4`）。

| FC | 含义 | mbpoll 读 | mbpoll 写 |
|----|------|-----------|-----------|
| 4 | 输入寄存器 | `-t 3` | 只读 |
| 5 | 线圈 | `-t 0` | `-t 0`，值 0/1 |
| 6 | 保持寄存器 | `-t 4` | `-t 4` |

```bash
# 读 BMS1 SOC（yc11 @10011，FC4，Scale 1000）
mbpoll -0 -t 3 -a 1 -r 10011 -c 1 -p 1501 127.0.0.1

# 写 PCS1 启停（yx3 @1003，FC5）
mbpoll -0 -t 0 -a 1 -r 1003 -p 1601 -1 127.0.0.1 1

# 写 PCS1 有功 100 kW（yt0 @40000，FC6，Scale 10 → 1000）
mbpoll -0 -t 4 -a 1 -r 40000 -p 1601 -1 127.0.0.1 1000
```
