# 物理引擎演进方案

## 目标定位

把仿真器的演进定义为：

> **从「编排设备输出结果」，演进为「根据设备模型与连接关系，求解电站状态」。**

不是增加「环流规则」「并机分配规则」，而是逐步完善设备的数学模型、网络约束和时间推进，让这些现象自然出现。环流、并机、功率均分等只作为验证场景，不作为特例算法的理由。

## 一、范围与边界

第一版目标：

**三相平衡基波相量网络 + 设备平均动态模型 + 电池/热耦合。**

- 能描述：电压、电流、有功、无功、相角及控制响应。
- 暂不承诺：PWM 波形、谐波、不平衡故障、合闸瞬间的电磁暂态峰值、快速保护精度。
- **分岛/合岛**作为验证场景时，不验收涌流峰值或开关 EMT。合闸后的准稳态验收要分两种：同步并网应收敛并再分配功率；失步并网允许不收敛并报失步，后者不收敛不算求解 bug。

继续使用 C#，保留现有协议、组态编辑器、设备目录和展示体系；先保证物理关系正确，再根据实测性能决定是否优化语言、步长或求解方式。不默认引入 C++/Rust、微秒级 EMT 或 FMI。

澄清一点：**设备状态空间模型与节点方程求解并不冲突**——前者描述设备如何变化，后者保证连接起来的设备同时满足电路约束，两者都需要。

## 二、目标架构：把职责分开

```text
EMS / CLI / Web / 内置策略
             │
          控制命令
             ▼
┌──────────── PlantEngine ────────────┐
│ 仿真时钟、命令时序、事件、状态提交    │
│                                    │
│ 设备控制器 ──参考值──► 设备物理模型   │
│     ▲                     │        │
│     │                 端口方程     │
│     │                     ▼        │
│     └──实测量────── 网络约束求解器   │
│                           ▲        │
│                     编译后的拓扑   │
│                                    │
│ 电气损耗──►热；温度──►设备参数     │
│ 交流端口功率──►直流能量结算        │
└────────────────────────────────────┘
             │
        已提交状态快照
             ▼
      协议投影 / 电表 / UI
```

### 各层责任

| 层 | 应该负责 | 不应该负责 |
|---|---|---|
| 设备物理模型 | 自身端口关系、内部储能、损耗、状态演化 | 查询邻机数量并决定如何均分 |
| 设备控制器 | PLL、下垂、PI、参考值、限流策略、保护逻辑 | 直接把目标功率写成实际功率 |
| 拓扑 | 哪些端口连接、开关如何改变连接 | 根据 EMU 分组推测电气连接 |
| 网络求解器 | 电流守恒、设备约束、节点电压与支路电流 | 特判「黑启动时应该给多少无功」 |
| 时间调度器 | 步长、事件、采样、提交顺序 | 用机器运行快慢改变物理结果 |
| 协议和展示 | 单位转换、编码、读取已提交结果 | 修补电压、电流或设备运行状态 |

**控制策略仍然可以包含人为规则。** 例如现有 EMU 将总功率指令均分给 PCS，是合理的控制策略；需要取消的是「实际输出也必然均分」的假设。

现有指令派发可以作为控制层保留：`EssSimModelApi/Mappers/EmuPowerDispatcher.cs:21`。

## 三、设备模型应该怎样组织

### 1. 每个设备统一描述四类信息

| 信息 | 示例 |
|---|---|
| 参数 | 电阻、漏抗、容量、变比、效率曲线 |
| 内部状态 | SOC、极化电压、温度、控制器积分量、内部相角 |
| 端口关系 | 电压与电流如何关联，能量如何交换 |
| 离散行为 | 启停、接触器、限流状态、保护动作 |

模型可以很简单，但**简单模型也必须自洽**。例如电池先采用 OCV 加内阻，之后升级成一阶 RC、二阶 RC；这些是电池模型精度的演进，不应要求引擎增加「电池电压回弹专用规则」。

### 2. 按设备逐步完善模型

| 设备 | 第一阶段模型 | 后续精度演进 |
|---|---|---|
| 线路 | 正序等效阻抗，连接两端节点 | 温度相关电阻、分布参数 |
| 变压器 | 变比、相移、漏阻抗、励磁支路 | 多绕组耦合、更完整损耗及磁化模型 |
| 断路器 | 接通/断开改变网络约束 | 动作延迟、保护配合 |
| 电网 | 电压源及等效阻抗 | 电压、频率扰动和更丰富的外部电网模型 |
| 负载 | 明确的阻抗/电流/功率特性 | ZIP、动态负载 |
| 电池 | OCV、内阻、SOC、热状态 | RC 极化、温度依赖、老化反馈 |
| PCS | **阶段 2 最小端口：** 受控电压源（或 Norton）串有限输出阻抗，参考值仍取现有控制器；**阶段 3：** 控制与物理分离后的平均变流器 + 直流能量约束 | 经验证的滤波器及完整控制动态 |
| 光伏 | 可用直流功率与逆变器控制 | 更完整的阵列、MPPT 动态 |

参数应记录来源：厂家数据、试验辨识或估算；不能为了让某个场景「看起来正常」随意调整阻抗。

### 3. PCS 要分清「控制参考」和「物理输出」

**构网模式：**

```text
电压/频率参考
    ↓
下垂及电压控制
    ↓
内部电势与相角
    ↓
输出支路模型
    ↓
网络求解得到实际端口电压、电流
```

**跟网模式：**

```text
P/Q参考 + PLL测量
    ↓
电流参考与控制
    ↓
变流器平均模型
    ↓
网络求解得到实际输出
```

两者都受直流电压、可用能量、电流能力等约束，测量反馈必须来自求解后的端口。

**引擎中不需要单独的 `CalculatePcsCirculatingCurrent()` 来决定各机电流。** 环流是这些设备连接后得到的支路电流特征，必要时可以另外计算诊断指标，但指标不能反过来替代求解。

**构网 PCS 进入网络的准入条件：** 必须带有限输出支路（滤波器/电缆/等效电抗），才能与其它源接到同一节点。两个理想电压源直接并联会使节点方程奇异或病态；此时不得退回「平均电压」或「选主源」。无输出支路的电压源只能单独给一个岛定压，禁止并联接入。

## 四、物理引擎的核心规则

### 1. 连接产生约束，而不是传递「谁覆盖谁」

目前端口有 `Input/Output` 快照：`EssDeviceSimModel/Model/ElectricalPort.cs:3`。这可以继续作为数据展示结构，但物理端口需要增加独立的求解语义：

- 相连端口共享节点电压。
- 节点满足电流守恒。
- 支路满足设备自己的电压—电流关系。
- 设备内部状态满足状态方程。

可统一表达为：

```text
dx/dt = f(x, y, u)    设备动态
0     = g(x, y, u)    网络与设备代数约束
```

其中：

- `x`：SOC、温度、控制器状态等；
- `y`：节点电压、支路电流等；
- `u`：外部命令和环境输入。

求解器装配这些方程，而不是按设备类型写业务流程。

### 2. 使用通用节点方程求解

建议以**节点导纳装配为基础，必要时使用改进节点分析（MNA）**，支持电压源、变压器等约束。

- 线性部分求解线性方程组。
- 非线性设备通过残差与迭代求解。
- 网络结构不变时复用矩阵结构。
- 求解失败要明确报告，不能退回「平均电压」或补额定值。
- **生产失败兜底：** 冻结上一拍已提交的**全部状态**（电气量、SOC、热、PI 积分、保护计时一并保持），置求解失败诊断位，协议层报故障。仿真逻辑时钟可以前进（表示「这一拍没解出来」），但不得按 stale 电气量继续积分动态。不得静默沿用旧结果假装本步已解，也不得停掉 Modbus 服务。
- 限流饱和、构网/跟网切换、断路器变拓扑是**离散模式事件**，不是求解失败：从已提交状态重装配后再解，不得在 Newton 迭代内改模式并继续累加残差。拓扑未变的限流饱和只需重装配方程（回到步骤 4）；断路器变拓扑等改变连接的事件回到步骤 2。

这并不意味着要做 SPICE：**保留节点方程的通用性，同时限制设备库和动态模型的复杂度。**

求解器内部从阶段 2 起固定尺度策略（SI 装配后按基准值缩放，或全程 pu）；设备参数与协议 IO 仍用有名值。不要设备一套单位、矩阵一套单位。

### 3. 相角基准与频率源是两件事

每个电气连通岛各自处理，全站不得共用一个 \(\omega\)。「共同旋转参考系」指**岛内**坐标。电压相角与功率因数角分开。

两个角色不可互换：

| 角色 | 作用 | 不是什么 |
|---|---|---|
| **角基准（datum）** | 纯数学：去掉 MNA 相角奇异行，可固定某节点 \(\theta=0\) | 不注入功率，不定义频率，不让无源母线带电 |
| **频率源** | 决定该岛 \(\omega\) | 并网岛由电网 slack 强制 \(\omega\)；黑启动/孤岛由构网机的 \(\delta\) 动态涌现 \(\omega\) |

- 不能用「设一个节点 \(\theta=0\)」去定义频率。
- 频率来自该岛频率源及测量模型，而不是各机频率取平均，也不是全站 `SystemFrequencyResolver` 选一个源覆盖所有岛。
- 多个电气孤岛可以具有不同频率。
- **分域并网岛（接到上层 \(V_\mathrm{th}\angle\theta_\mathrm{th}\)）的角/频由 \(V_\mathrm{th}\) 锁定**，不得再自选 datum 把某节点设为 \(\theta=0\)。
- **自由 datum 只给无源岛**（岛内没有任何已知相角的电压源）。由 GFM 状态 \(\delta\) 驱动的黑启动岛：\(\delta\) 已是网络的已知相角输入，不需要另设 \(\theta=0\)，以免与 \(\delta\) 冲突。完全无源、无 \(V_\mathrm{th}\)、无 GFM 电势的岛才自由选 datum 去奇异。
- 并网岛若仍需去掉相角奇异，应把 \(V_\mathrm{th}\) 的相角当作该岛参考，而不是另选一套 \(\theta=0\)。

### 4. 明确单位与方向

- 内部物理量采用统一 SI 单位，数值求解按基准值缩放；不必为了标幺化把全部业务代码都改写。
- 统一采用端口电流「流入设备为正」等约定，协议层再转换成现有充放电符号，避免各设备各自解释正负。
- 电表也应明确绑定：**测哪个节点的电压，以及哪条支路的电流。** 不能把节点电流汇总当成所有位置的电表电流。

### 5. 删平均之前必须成立的硬规则

以下不是场景补丁，而是网络内核接替生产路径的准入条件。不满足时**不得删除**平均电压等捷径，否则方程无法求解或会静默算错。

1. **构网源必须带有限输出支路**方可并入同一节点。见第三节 PCS 准入条件。阶段 2 用最小端口模型（受控源串阻抗）即可满足本条。
2. **角基准与频率源按电气连通岛分别定义**，全站不得共用一个 \(\omega\)。datum 只去奇异，且仅无源岛可自由选；GFM 驱动的黑启动岛用 \(\delta\) 状态，不另设 \(\theta=0\)；接到 \(V_\mathrm{th}\) 的并网岛角/频由戴维南给定。
3. **首期控制参考仅依赖上一步已提交的端口测量。** 本步只解网络与设备代数约束。PLL 与 PI 积分必须用状态，一拍滞后可接受；代数下垂本可隐式，首期一并显式是简化，不是最终形式。滞后引入的步长上限在阶段 1 重放测试里量化，**分域边界上一拍延迟的 \(P/Q\) 反馈环一并纳入同一项量化**。下垂是否改隐式，留到「收紧代数环」时再决定。
4. **同一耦合口同一时刻只有一个电气真值来源。** 交流网络解出端口 \(P\) 后，直流侧只做能量结算（例如 \(I_\mathrm{dc}=P_\mathrm{ac}/V_\mathrm{dc}\) 加损耗），禁止 `Pcs.Update` / `Bms.UpdatePhysics` 再算一条电气路径。热模型吃损耗积分，不反向改写本步电压电流。
5. **分域接替时，求解器接缝也必须是单一真值边界。** 上层径向提供戴维南电压源，下层 690 V 岛提供注入 \(P/Q\)；每拍单向交接一次，并规定求解顺序。上下两域同一拍视为**一个提交单元**。不得在 690 V/35 kV 接缝处再开第二条电气路径。

## 五、时间推进和状态管理

这是与网络方程同等重要的基础。当前时钟使用墙钟间隔：`EssDeviceSimModel/EnergyStorageSys.cs:536`。建议改为逻辑仿真时间，墙钟只负责控制运行速度。

### 每一步的执行过程

```text
1. 冻结本步命令和已提交状态
2. 处理到期事件，更新连接或设备模式
3. 按采样周期、用上一步已提交测量计算控制参考（首期显式）
4. 装配设备方程和网络约束
5. 求解候选电气量与动态状态（迭代不推进时间）
6. 检查收敛与模式事件：拓扑未变的限流饱和回到步骤 4 重装配；断路器变拓扑等回到步骤 2。分域期：上层域事件重跑 a–d；下层域事件只重跑 c–d（上层输入是上一拍已提交 \(P/Q\)，不受本拍下层事件影响）。均属本拍候选，不算失败、不冻结。
7. 由交流端口功率结算直流电荷与损耗，再累计热量
8. 一次提交状态，发布快照
```

分域期步骤 4–7 在上下两域按第六节边界顺序展开，但步骤 1 与步骤 8 仍是**全域一次**：冻结一份已提交快照，候选解全部成功后才替换。不允许下层先提交、上层后失败。

关键约束：

- **迭代十次不代表时间前进十次。**
- 求解迭代不能重复累加 SOC、PI 积分、电量或保护计时。
- 失败重算必须从同一已提交状态开始。
- **求解失败时整步不提交**：电气与动态（SOC、热、PI、保护计时）一起冻结。禁止「电气冻住、电量仍按上一拍 \(P\) 积分」。
- 协议和 UI 不能读到「电压已更新、电流还没更新」的半步状态，也不能读到「下层已提交、上层未提交」。
- 内置 EMS 也应通过命令边界参与，不能在步进末尾直接改物理状态。
- 步骤 3 的控制与步骤 5 的网络在首期解耦；不要用本步尚未提交的 \(V,I,P,Q\) 算下垂后再写进同一迭代。
- 一拍控制滞后会限制稳定步长。阶段 1 用重放测试量化该上限；分域 \(P/Q\) 延迟反馈环用同一套用例一起测。不得靠加大下垂系数掩盖步长过大。

多速率随后建立在这个基础上：

- 电气与快速控制采用较快步长；
- 电池电荷、电能交换持续累计；
- 热和老化按较慢周期推进；
- 慢模型接收区间累计能量，而不是只取最后一拍功率。
- **跨速率代数环：** 快拍结算 \(I_\mathrm{dc}=P_\mathrm{ac}/V_\mathrm{dc}\) 时，\(V_\mathrm{dc}\) 冻结为上一次慢拍已提交值，不做预测插值。慢拍再用区间累计电荷更新 \(V_\mathrm{dc}\)。

加速仿真应改变执行速度或推进步数，而不是只放大 SOC、忽略热与控制的时间。

### 拓扑迁移原则

组态已经保存节点和端口连接：`Web/Topology/TopologyModels.cs:51`。应直接编译它们，而不是再次根据单元数生成另一张网络：

- EMU、分组是管理关系，不自动决定电气连接。
- 画布移动、列表排序不能改变物理结果。
- 未连接的设备保持未连接，不默默补接默认设备。
- 电气设备 ID 与外部协议编号分开管理。
- 首期不支持的接线应明确拒绝，不能悄悄降级成径向结构。

「保留协议」指保持外部点位和控制语义稳定，**不是说内部适配层完全不用改**。

### 分域接替的边界接口

阶段 2 会出现两个求解器同时活着：新内核管 690 V 岛，径向引擎管 35/220 kV。这是第二道电气接缝，必须和 AC/DC 一样遵守「单一真值」。

每拍单向交接一次，顺序固定。这 4 步嵌在第五节步骤 4–7 之内，**不是另一次提交**：

```text
第五节 1–3：全域冻结命令、处理事件、算控制参考
  4–7 展开为：
    a. 上层径向用上一拍下层已提交的 P/Q 注入，解 35/220 kV
    b. 上层把单元变高压侧结果折成低压侧戴维南（Vth∠θth, Zth）交给下层
    c. 下层用该戴维南作为岛的外部端口，解 690 V（含直流能量结算候选）
    d. 下层算出变压器低压侧 P/Q，写入本拍候选，供下一拍上层使用
第五节 8：仅当 a–d 与动态候选全部成功，才一次替换全域已提交快照
```

- 上层 = 电压源戴维南；下层 = 功率注入。不得双方都当电压源，也不得双方都当电流源。
- 本拍下层看到的 \(V_\mathrm{th}\) 来自上层本拍；上层本拍用的 \(P/Q\) 来自下层**上一拍**已提交量。这是与硬规则 3 同类的一拍延迟环，增益大时可能振荡；阶段 1 与控制滞后一并量化稳定步长。
- 接到 \(V_\mathrm{th}\angle\theta_\mathrm{th}\) 的下层岛是并网岛：角/频跟随 \(V_\mathrm{th}\)，不得再自选 \(\theta=0\) 的 datum。
- **变压器归属：** 分域期单元变漏抗并入上层戴维南 \(Z_\mathrm{th}\)，下层端口只看到 \(V_\mathrm{th},Z_\mathrm{th}\)，禁止两侧各算一半。阶段 4 全网由同一内核接管后，单元变并入内核设备库，删除此戴维南边界。
- **事件与失败分开：** 离散模式事件仍是本拍候选，不算失败、不冻结。方向必须与一拍延迟一致：
  - **上层事件**（35 kV 断路器变位等）改变 \(V_\mathrm{th}\) → 重跑 a–d，下层必须跟随本拍新的戴维南。
  - **下层事件**（PCS 限流/跳闸等）只重跑 c–d。上层 a 的输入是上一拍已提交 \(P/Q\)，本拍冻结、不受影响，无需重解。下层本拍 d 写入的候选 \(P/Q\) 在**下一拍**才进入上层。
  - 回退起点仍按单域规则：拓扑未变回步骤 4，变拓扑回步骤 2；然后按上面范围重跑，不要做成上下同步迭代。
  - 只有 a–d 或动态求解真正失败，才走第四节整步冻结兜底。不允许下层先提交、上层后失败。
- **影子期边界隔离：** 影子模式中新核跑自己的 a–d，\(P/Q\) 与 \(V_\mathrm{th}\) 只用影子上一拍，不回写生产边界；旧径向仍独立对外。禁止把影子结果接到生产戴维南或生产注入。
- 正式接替全网后删除此边界，只留一个内核。

### 物理捷径退役表

平均电压不是唯一要删的捷径。每条捷径在对应设备模型与硬规则具备之前不得删除；具备之后不得继续当物理用。

| 现有捷径 | 性质 | 退役前置 |
|---|---|---|
| `ElectricalBusNode.ApplyLocalVoltageSources` 多源电压/频率算术平均 | 错误物理规则 | **仅对被新内核接管的节点立即禁止。** 未接管的径向节点（如分域期间的 35 kV 母线）暂留平均，并标记为已知偏差；该层被同一内核接管后立即删除 |
| `EssIslandBusLogic` 构网电压/频率平均 | 同上 | 690 V 岛接管后，岛内逻辑删除；上层径向估算暂留并标记已知偏差 |
| `BlackStartSteadyLossShareMode` / 励磁无功硬摊 | 把负荷分配写成物理 | 网络能解出各机实际 \(P,Q\) |
| `BlackStartJoinShare` 切入后无功斜坡接手 | 可视为控制策略 | 若保留，必须走控制层参考值，不能改写求解结果 |
| 活母线「禁止第二台 V/f」 | 联锁/控制 | 可留在控制层；**不能**在网络无解时当作物理兜底 |
| `PcsBmsDcCouplingLink` 在网络步之后覆盖 PCS/BMS 电气量 | 双真值路径 | 硬规则 4：单一电气真值 + 直流能量结算 |

删除顺序服从硬规则，不服从「先修环流场景」。退役范围按节点所有权：**被新内核接管的节点禁平均；未接管的径向节点暂留并记为已知偏差。**

## 七、按通用能力划分迭代

| 阶段 | 核心交付 | 验收重点 |
|---|---|---|
| **1. 统一基础契约** | 单位/方向、状态所有权、逻辑时钟、命令时序、快照提交；控制显式用上一步测量 | 重放一致、状态不重复积分、读取无半步状态；量化一拍滞后（含分域 \(P/Q\) 环）下的稳定步长上限 |
| **2. 建立网络内核** | 通用装配与求解（导纳/MNA）；源、阻抗、变压器、开关；**最小 PCS 端口模型**（受控源串有限阻抗，参考值仍取现有控制）。先影子比对一个单元 690 V 岛，通过后再生产接替；经戴维南/注入边界与上层径向交接，不是一上来全站 220/35/690 | 解析电路、KCL、功率平衡、设备排序不影响结果；无输出支路的电压源拒绝并联；该岛内不再平均电压；边界上只有一套 \(V_\mathrm{th}\) 与一套 \(P/Q\)；分域上下同一拍原子提交 |
| **3. 接入动态设备** | PCS 控制与物理分离（替换阶段 2 的最小端口，不是从零引入 PCS）；电池与直流能量耦合；事件与限流 | 动态响应、状态连续、端口能量守恒；交直流同一真值 |
| **4. 接入真实工程** | 组态连接编译、完整设备覆盖、协议及 UI 状态投影；上层 35/220 kV 再切到同一内核 | 连线即运行网络，现有工程与联调语义可用 |
| **5. 提升精度与效率** | 多速率、参数辨识、更高阶设备模型、性能优化 | 步长收敛、参考模型对标、目标规模性能 |

**阶段名称不叫「解决环流」「修复黑启动」**；这些现象放进各阶段的验收集。阶段 2 把 690 V 岛作为首个接替域，是规则覆盖范围的扩展顺序，不是给并机写特例算法。上层径向潮流可以暂时保留；**被接管节点禁止平均，未接管径向节点暂留平均并记为已知偏差。** 阶段 2 必须带上最小 PCS 端口模型，否则并联岛不可解。

新内核从阶段 2 起即可在独立测试宿主运行。**影子比对允许点提前到阶段 2 生产接替之前**：先在真实工程拓扑上影子跑该 690 V 岛（新核算、旧核仍对外），对比通过后再切生产。影子 a–d 只用影子自己的上一拍 \(P/Q\)，不写入生产边界。阶段 3 的影子模式继续用于后续域。正式接替时，同一耦合网络只能由一个物理内核推进，不能新求解器算完后再让旧 `Update` 覆盖结果。第四节硬规则未满足前，不删除捷径表中的物理平均。

## 八、如何证明不是「换了一套看起来合理的数值」

验证分为三层。

### 物理不变量

持续检查：

- 节点电流残差；
- 设备方程残差；
- 功率与能量收支；
- 无源设备不凭空发电；
- 断开的支路没有导通电流；
- 修改设备遍历顺序不改变物理结果。

### 模型正确性

用解析解、参考仿真和实测数据分别验证阻抗、变压器、电池、控制器等模型，并做步长收敛检查。数值残差、模型误差和参数不确定性应分开衡量，不能统一宣称「误差小于 1%」。

### 系统场景

黑启动、并机、电压不一致、相角偏差、负载突变、分岛合岛等用于检查：

> **不增加场景专用计算时，设备模型与通用约束能否自然得到合理结果。**

分岛合岛不验证合闸涌流峰值。准稳态分两种验收：

- **同步并网**（合闸前幅值/频率/相角在预同步窗口内）：应收敛到共同岛，功率按网络再分配。
- **失步并网**（频率或相角差过大）：允许不收敛，应报失步/求解失败并走整步冻结兜底。此时不收敛是物理正确，不算 bug；禁止加人为阻尼去凑「一定收敛」。

与第一节「不承诺合闸 EMT」一致。

旧模拟器适合验证协议兼容性，不应作为新物理结果的唯一真值；目前验证「电压必须取平均」的测试，也需要改成验证网络约束。

## 九、最容易设计错的地方

1. 把 MNA 误当成只能求静态潮流——它与设备状态空间共同构成 DAE，可支持动态。
2. 候选迭代过程中暗中推进 PI、SOC 或保护计时，导致时间被多算。
3. 用理想电压源、假电流反馈制造「稳定并机」，掩盖真实支路电流；或无输出支路仍并联，方程奇异后悄悄平均。
4. 把角基准（datum）当成频率源：用 \(\theta=0\) 定义 \(\omega\)；在 GFM 黑启动岛再设一套 \(\theta=0\) 与 \(\delta\) 冲突；分域并网岛仍自选 datum，与 \(V_\mathrm{th}\) 相角打架。
5. 新求解器算完后仍让旧耦合逻辑写状态，或把旧输出当真值；交流已解出 \(P\) 后直流再积分一遍。
6. 分域接替时 690 V 与 35 kV 双方都当电压源（或都当电流源），在变压器接缝处再造一套双真值；或分域期漏抗两侧各算一半。
7. 分域期下层先提交、上层后失败，或电气冻结而 SOC/PI 仍积分，造成半步状态。
8. 把分域模式事件当成求解失败冻结；或上层事件未重跑 a–b，使下层用过时 \(V_\mathrm{th}\)；或下层事件去重解上层，破坏一拍延迟。
9. 阶段 2 没有最小 PCS 端口模型就去接替并联岛，方程不全，只能退回平均。
10. 阶段 2 未影子比对就切生产接替；或影子 \(P/Q\) 写进生产戴维南。
11. 把限流/保护切模式塞进同一次 Newton；或拓扑未变的限流也整步退回步骤 2。
12. 为了「先看到环流」去改分配公式，而不是补设备支路并删平均。
13. 求解失败时静默沿用旧电气量或退回平均；或只冻电气、动态继续走。
14. 快拍用预测的 \(V_\mathrm{dc}\) 结算直流电流，打开跨速率代数环。
15. 失步合闸强制要求收敛，用人为阻尼凑稳态。

## 结论

**建议从「统一模型契约与时间状态管理」和「最小通用网络内核」开始，而不是先改某一条现象逻辑。** 网络内核先覆盖一个 690 V 岛：带最小 PCS 端口模型、经戴维南/注入边界与上层径向交接、分域同一拍原子提交；影子比对通过并满足第四节硬规则后再删除该岛上的平均捷径。环流、并机是验收信号。后续每增加一种设备模型或提升一级精度，都通过同一套连接、求解和验收机制生效，这才是这次迭代应建立的核心能力。
