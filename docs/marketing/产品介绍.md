# 仿真模拟器（EssSimulator）— 产品介绍

> 用途：发朋友圈/行业群的短版文案，以及发给潜在合作方的完整版。
> 文中所有功能均为当前版本真实能力，演示前请先按「演示录屏脚本」录制素材。

---

## 一、一句话定位

**一台电脑，一座虚拟电站——储能与光伏，让 EMS 在真机到货之前就完成闭环联调。**

## 二、解决的痛点

储能 / 光伏联调最贵的三件事，在这台电脑上都不用等：

| 痛点 | 现状 | 我们的解法 |
|---|---|---|
| 真机没到货，联调只能等排期 | 排产周期拖慢研发节奏 | 一台电脑随时可跑的"虚拟电站" |
| 半实物仿真（HIL）太贵 | 几十万起步，还要专用硬件 | 纯软件，普通 PC 即可运行 |
| 假从站"接口通了、物理全假" | mock 数据没有因果链，bug 到真机才爆 | PCS 爬坡、光伏 MPPT/限发、SOC 积分、断路器分合、电热耦合——数值之间有真实的因果链 |

## 三、它能干什么（全部真实功能）

### 1. 一座"会动的"电站
- **电池**：堆 → 簇 → Pack → 电芯逐级建模，SOC 随充放电积分变化，簇间均衡；
- **PCS**：有功/无功指令爬坡、并网/离网、**黑启动** V/f 建压、直流/交流耦合；
- **光伏**：组串逆变器 + 箱变（MVS）、组件 IV / 辐照 / 双面反照率 / 年限衰减、限发与无功；可组光储或纯光伏工程；
- **一次设备**：主变/单元变（含损耗、阻抗、励磁涌流）、主/单元断路器、站用负载；
- **电热耦合**：环境温度、柜体热网络、空调闭环、温度降额、电池老化。

### 2. 和现场一致的 Modbus 接口
外部 EMS/主站**完全按连真设备的方式**连它，几乎不用改代码：

| 虚拟设备 | 服务名 | 默认端口 |
|---|---|---|
| 并网点电表 | simEm | 1500 |
| BMS 第 N 路 | simBmsN | 1501+ |
| EMU 第 U 单元（含 PCS） | simEmuU | 1601+ |
| 光伏 Logger 第 P 单元 | simPvP | 1801+ |
| 光伏低压电表 第 P 单元 | simPvMeterP | 1901+ |

支持遥测读取、控制下发（启停/并网/功率设定）、状态反馈、通讯中断模拟（`link` 指令）。

### 3. 可视化 Web 界面（默认 5050 端口）
- **主电气接线**：2D 单线图 + **3D 场景**，断路器状态、P设/P实、光伏实发、电压电流实时联动；
- **电池监控**：堆/簇/电芯逐级下钻，SOC、电压、温度曲线；
- **告警与门限**：簇级三级告警、BMS 保护状态、门限在线配置；
- **命令与自动化**：控制台命令 + `dpctest` 脚本一键重放。

### 4. 组态编辑器（旗舰功能）
- **拖拽式搭建电站拓扑**：电网、母线、断路器、变压器、电表、负载、EMU、PCS、光伏单元、BMS、直流母线等模板；
- **标准拓扑向导**：一键生成 1–20 单元径向电站（储能 / 光伏 / 光储）；
- **多工程管理 + 设备库**：搭好的电站存成工程，可随时切换、复用。

## 四、与半实物仿真的对比

| 维度 | 半实物仿真（HIL） | 仿真模拟器 |
|---|---|---|
| 硬件 | 实时仿真机（数十万起） | 普通电脑 |
| 上手 | 专用培训、环境复杂 | 解压即用（自包含程序，无需 .NET 运行时） |
| 场景 | 保护/装置级实时性测试 | **EMS/主站逻辑联调、策略验证** |
| 成本 | 高 | 社区版免费，商业版一次买断 |

> 定位说明：我们不做保护装置的微秒级实时测试（那是 HIL 的领域），我们解决的是**控制与通讯联调**——EMS 90% 的联调工作量都在这里。

## 五、适用对象

- **EMS / 主站研发团队**：策略开发、闭环验证、回归测试；
- **BMS / PCS / 光伏设备厂商**：与 EMS 的协议一致性联调；
- **系统集成商 / EPC**：投标演示、项目培训；
- **高校 / 培训机构**：储能 / 光伏系统教学与实训。

## 六、获取方式

- **社区版**：免费下载，2 单元规模评估（本机、非商业用途）；
- **商业版**：一次性买断，完整拓扑/多单元/全部功能；
- **定制版**：按项目适配点表与特殊设备。
