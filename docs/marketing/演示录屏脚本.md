# 演示录屏脚本 — 仿真模拟器

> 三个场景共约 10 分钟，建议分 3 条视频发布，也可合成一条长视频。
> 本脚本每一步操作都可在当前版本真实执行，先本地走一遍再录，避免翻车。

---

## 〇、录制准备

| 项 | 建议 |
|---|---|
| 分辨率 | 1920×1080，横屏 |
| 录屏工具 | macOS：QuickTime（免费）；Windows：OBS / Bandicam |
| 环境 | 开发环境 `dotnet run` 或发布包 `start.sh`；浏览器打开 `http://localhost:5050` |
| Modbus 工具 | 命令行 `mbpoll`（免费）或 Windows 版 Modbus Poll |
| 素材顺序 | 先拍场景二（闭环联调）最有说服力；场景一、三作补充 |
| 开场 | 每段视频前 3 秒黑屏字幕：产品名 + 一句话定位 |

**必须提前演练的命令序列**（脚本里的每一步都要先手动跑通一次）：
```bash
# 典型联调四连（场景二核心）
dpc simEmu1.yx0 set 1        # 单元高压合闸
esscmd setbms1 power on      # BMS 直流并网
dpc simEmu1.yx3 set 1        # PCS1 启动
dpc simEmu1.yt0 set 1000     # 有功 100 kW（Scale 10 → 写 1000）
```

---

## 场景一：从零建站（约 3 分钟）— 展示组态编辑器

**脚本主线**：启动 → 打开组态编辑器 → 向导一键生成 → 保存工程 → 应用 → 看主接线。

| 镜头 | 画面 | 操作 | 旁白 / 字幕（可直接念） |
|---|---|---|---|
| 1-1 | 终端启动画面滚动到"协议服务就绪" | 运行 `dotnet run` 或 `start.sh` | "储能与光伏仿真模拟器，一台电脑就是一座电站。启动后自动拉起 Modbus 服务——电表、BMS、EMU，工程含光伏时还有 Logger 和低压电表。" |
| 1-2 | 浏览器打开 5050，首页 | 打开 `http://localhost:5050` | "这是 Web 管理界面，接线图、电池、告警、组态编辑，全部在这里。" |
| 1-3 | 切到「组态编辑」页 | 顶部菜单 → 组态编辑 | "搭一个电站，不用写一行配置。点开标准拓扑向导——" |
| 1-4 | 向导弹窗，填 EMU / 光伏数量 | 向导：EMU 数量 = 4（光伏可填 0 或与储能并列） → 生成 | "输入 4 个储能单元，一键生成标准径向拓扑：电网、主断、主变、35kV 母线、4 台 EMU、8 路 BMS 全部自动连好。需要光储时再填光伏单元数即可。" |
| 1-5 | 画布展示生成的拓扑（可拖动一个节点） | 拖动一个 EMU 节点 | "节点可以拖拽调整，变压器参数、BMS 电芯配置都能在右侧直接改。" |
| 1-6 | 保存工程 | 填工程名 → 保存工程 | "存成工程，随时可以切换。" |
| 1-7 | 系统配置页选择该工程并应用 | 系统配置 → 选工程 → 确认 | "应用到仿真，重启后按 4 单元电站重建设备和 Modbus 端口。" |
| 1-8 | 主接线页展示 4 单元电站 | 切到主接线 | "一个 4 单元储能电站就这样建起来了。" |

**字幕强调**："搭电站，几分钟；改配置，零代码。"

## 场景二：闭环联调（约 5 分钟）— 核心卖点，务必拍好

**脚本主线**：Web 看全站 → 打开 Modbus 工具 → 模拟 EMS 下发控制四连 → 观察功率爬坡/SOC 联动 → 修改负载看潮流重新分配。

### 分镜 A：Web 主接线总览（0-40s）

| 镜头 | 画面 | 操作 | 旁白 |
|---|---|---|---|
| 2-1 | 主接线页全览 | 打开主接线 | "先看全站：主变、4 台单元、双 PCS、电池、负载、并网点电表，和真实电站监视大屏一致。光储工程还会画出光伏箱变与方阵。" |
| 2-2 | 切 3D 视图（可选加分） | 切到 3D 视图 | "还有 3D 场景，适合给领导汇报、给客户演示。" |
| 2-3 | 电池页下钻 | 电池 → 某单元 | "电池从堆到簇到电芯逐级下钻——比如看第 1 单元 BMS 的 SOC、直流电压。" |

### 分镜 B：Modbus 闭环控制（40s - 3min）★ 全片最重要

| 镜头 | 画面 | 操作 | 旁白 |
|---|---|---|---|
| 2-4 | 打开 Modbus 工具连 simEmu1（1601） | mbpoll / Modbus Poll 连 1601 | "现在模拟 EMS，用和现场完全一样的 Modbus TCP 去控制它。先连第 1 单元的 EMU——端口 1601。" |
| 2-5 | 下发"单元高压合闸" | `dpc simEmu1.yx0 set 1` | "第一步，单元高压合闸。" |
| 2-6 | 下发"BMS 直流并网" | `esscmd setbms1 power on` | "第二步，BMS 直流侧并网，电池直流电压上到 PCS 直流端口。" |
| 2-7 | 下发"PCS1 启动" | `dpc simEmu1.yx3 set 1` | "第三步，PCS1 启动，运行状态变为待机/运行。" |
| 2-8 | 下发"有功 100kW" | `dpc simEmu1.yt0 set 1000`（Scale 10） | "第四步，下发 100kW 有功指令。注意——功率不是瞬间跳满，是像真机一样爬坡。" |
| 2-9 | 主接线页 P设/P实 | 切回主接线 | "看 P设 100kW，P实 正在爬坡趋近。这就是'有因果链的仿真'：不是假数据，是物理过程。" |
| 2-10 | BMS SOC 读数 | `dpc simBms1.yc11 get` | "再读电池 SOC，正在随时间积分变化。充一会儿，SOC 真的会涨。" |
| 2-11 | 读并网点电表 | `dpc simEm.yc19 get` 或 Web 电表区 | "并网点电表三相电压电流也一起联动。" |

### 分镜 C：负载扰动（3min - 4min）

| 镜头 | 画面 | 操作 | 旁白 |
|---|---|---|---|
| 2-12 | 改站用负载 | `esscmd setLoad activePower -500` | "改一下站用负载到 500kW，看潮流重新分配——变压器、表计都会跟着动。" |
| 2-13 | 主接线观察潮流变化 | 看变压器/表计数值 | "负载变化后，全站潮流重新平衡。EMS 策略在这种环境下验证，比 mock 数据可靠得多。" |

### 分镜 D：自动化回归（4min - 5min）

| 镜头 | 画面 | 操作 | 旁白 |
|---|---|---|---|
| 2-14 | dpctest 脚本执行 | `dpctest list` + `dpctest ramp_test` | "把整串操作保存成脚本，一键重放——联调回归测试必备。" |

**字幕强调**："接口和真机一致，行为和真机一致，成本是一台电脑。"

## 场景三：故障与恢复（约 3 分钟）— 展示保护与通讯演练

**脚本主线**：断路器分闸看并网路径变化 → 触发 BMS 告警看 EMS 响应 → 模拟通讯中断再恢复。

| 镜头 | 画面 | 操作 | 旁白 |
|---|---|---|---|
| 3-1 | 主断分闸 | `breaker set false` | "演练故障：主断路器分闸。并网 PCS 停机或转离网逻辑，主接线带电状态立刻变化。" |
| 3-2 | 观察主接线变化 | Web 主接线 | "断路器分了闸，潮流真的消失——拓扑状态和物理量是联动的。" |
| 3-3 | 主断合闸恢复 | `breaker set true` | "重新合闸，系统恢复。" |
| 3-4 | 触发 BMS 告警 | `dpc simBms1.yx21 set 1` | "再模拟电池簇二级告警——EMS 在真机上要处理的场景，在这里随便演练。" |
| 3-5 | 告警页查看 | Web 告警页 | "告警实时上送，EMS 可以读到完整的告警字。验证完清除。" |
| 3-6 | 模拟通讯中断 | `esscmd link bms1 off` | "甚至能模拟通讯中断：把 BMS 的 Modbus 监听关掉，EMS 立刻'连不上'。" |
| 3-7 | 恢复通讯 | `esscmd link bms1 on` | "一键恢复，重连后遥测自动全量刷新——断链重连的场景也能练。" |

**字幕强调**："真机上不敢试的，在这里随便试。"

- 正式发布前把演示里出现的 IP/机器名打码。
