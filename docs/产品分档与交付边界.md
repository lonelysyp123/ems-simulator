# 产品分档与交付边界

对外产品名：**仿真模拟器**。工程名：EssSimulator。  
**同一套代码**，通过配置开关 `Simulator.Edition.Name` 区分社区版 / 商业版 / 定制版；**演示版**为免授权评估包。发布用 `scripts/commercial/`。

---

## 1. 档位开关（核心）

```json
"Simulator": {
  "Edition": {
    "Name": "Community",
    "LockTopology": true,
    "MaxEssUnits": 2,
    "AllowDroopSlices": false,
    "AllowMainline3d": false,
    "AllowTopologyEditor": false
  }
}
```

| Name | 含义 | 白盒切片 | 主接线 3D | 组态编辑 | 拓扑规模 | 授权 |
|------|------|----------|-----------|----------|----------|------|
| `Community` / 社区版 | 免费试用 | **关闭** | **关闭** | **关闭** | 锁定，默认最多 2 单元 | 不需要 |
| `Commercial` / 商业版 | 一次性买断 | **开放** | **开放** | **开放** | 不锁定 | 需要 `license.txt` |
| `Custom` / 定制版 | 项目定制 | **开放** | **开放** | **开放** | 不锁定，可加特殊设备 | 需要 `license.txt` |
| 演示版（配置 Name 仍为 Commercial） | 对外评估包 | **开放** | **开放** | **开放** | 包内固定 2 单元 | **不需要** |

开发默认（根 `appsettings.json`）为 **Commercial**。  
社区包用 `configs/社区版.appsettings.json`（Name=Community）即可切换，无需改代码。  
演示包用 `configs/演示版.appsettings.json` + `./scripts/commercial/publish-demo.sh`，含预设组态工程。

---

## 2. 商业路径

```
演示版（免授权评估） / 社区版（免费下载）
        → 商业版（一次性买断） → 定制版（按需加设备/功能）
```

| 档位 | 配置模板 | 授权 | 典型用途 |
|------|----------|------|----------|
| 社区版 | `configs/社区版.appsettings.json` | 不需要 | 2 单元、本机评估，高级 UI 关闭 |
| 演示版 | `configs/演示版.appsettings.json` | 不需要 | 2 单元、本机、组态/3D 全开，打开即用 |
| 商业版 | `configs/商业版.appsettings.json` | 需要 `license.txt` | 完整开发级能力 |
| 定制版 | `configs/定制版.appsettings.json` | 需要 `license.txt` | 项目拓扑 + 特殊需求 |

授权流程见 [授权说明.md](./授权说明.md)：用户取机器码 → 卖方签发 `license.txt` → 放运行目录启动校验。

发布：

```bash
./scripts/commercial/check-edition-drift.sh
EDITION=社区版 ./scripts/commercial/publish-windows.sh
EDITION=商业版 ./scripts/commercial/publish-linux.sh
./scripts/commercial/publish-all.sh
./scripts/commercial/publish-demo.sh          # 演示版（不在 ALL_EDITIONS 内）
EDITION=社区版 ./scripts/commercial/publish-macos.sh
```

点位表：商业发布携带完整 `pointmaps/models`，运行时按选型解析；未选型时回退 `standard`。  
旧名 `EDITION=充值版` 会映射为 **商业版**；仓外托管约定见 [充值版授权网关约定](./充值版授权网关约定.md)。

---

## 3. 交付边界（定制版）

**默认包含**：约定拓扑配置（含光伏单元模板）、点表（含 `pv/`）、自包含运行包、随包文档。  
**默认不包含**：非常规协议扩展、现场人天、HIL 等（合同单列）。

```bash
./scripts/commercial/sync-custom-from-root.sh   # 根配置 → 定制版（Edition=Custom）
```

---

## 4. 相关路径

| 路径 | 说明 |
|------|------|
| `Simulator.Edition` | 档位主开关 |
| `Simulator.License` | 是否要求 `license.txt` |
| `scripts/license/` | 取机器码 / 签发（签发脚本勿进社区包） |
| `docs/授权说明.md` | 授权流程 |
| `scripts/commercial/` | 发布与校验 |
| `configs/*.appsettings.json` | 社区/商业/定制/演示（及旧名充值版）模板 |
